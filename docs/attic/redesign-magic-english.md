# 쿼플 재기획 — 마법영자문

> 상태: **기획안 (구현 전)**.
> 방치형(`redesign-idle.md`)은 **폐기**한다.
> 8세 이하 UI 규격과 안전 규칙(`redesign-kids.md` 5·7절)은 살리되, **중학생까지** 넓힌다.

## 0. 한 문장

> **영어 단어가 곧 마법인 세계에서, 쿼카 커플이 단어를 배워 길을 연다.**

마법천자문이 한자를 마법으로 쓰듯, 우리는 **영어 단어를 마법으로 쓴다.**
싸워서 이기는 게임이 아니라 **막힌 곳을 단어로 여는 게임**이다.

## 1. 왜 이 구조가 맞나

마법천자문이 잘 된 이유는 "한자를 가르쳐서"가 아니다.
**한자를 알아야 다음 장면이 넘어가서**다. 배움이 곧 진행이다.

영어에 그대로 옮겨진다. 오히려 더 잘 맞는 게 하나 있다.

| 마법천자문 | 마법영자문 |
|---|---|
| 한자 한 글자 = 마법 하나 (火 → 불) | 단어 하나 = 마법 하나 (FIRE → 불) |
| 획순대로 쓴다 | **철자를 순서대로 놓는다** |
| 부수를 조합한다 (氵+ 由 = 油) | **접두사·접미사를 조합한다** (un + lock = unlock) |
| 뜻을 알아야 어디 쓸지 안다 | 뜻을 알아야 어디 쓸지 안다 |

철자 순서와 획순이 대응되는 게 특히 좋다. 영어에서 제일 지루한 게 스펠링 외우기인데,
**획을 긋는 손맛**으로 바꿀 수 있다.

## 2. 코어 루프

```
   막힌 곳을 만난다  →  무슨 마법이 필요한지 그림으로 보인다
        ↑                              │
        │                              ↓
   길이 열린다  ←  마법 발동 컷  ←  철자를 놓아 단어를 완성한다
```

한 번에 30초~1분. **한 단어 = 한 사건.**

### 예

> (앞에 얼음 벽. 쿼카가 오들오들)
> 파트너 말풍선: 😨 *"으… 차가워!"*
> 리더 말풍선: 💡 *"이럴 땐…!"*
>
> **[ F ][ I ][ _ ][ _ ]** ← 빈칸에 R, E 를 끌어다 놓는다
>
> **🔥 FIRE!** — 불 마법 컷 (화면 가득)
> 얼음이 녹는다. 파트너 말풍선: 😆 *"따뜻해!"*
> 📖 도감에 **fire 불** 등록

## 3. 스토리 전개 — 말풍선 + 표정 컷

글은 최소로, **표정이 대사를 대신한다.**

- 대사는 말풍선 하나에 **한 줄, 15자 이내**
- 말풍선 옆에 **표정 컷**이 항상 붙는다 (쿼카 얼굴 크게 잘라낸 그림)
- 감정은 **이모지 + 표정 컷 두 겹**으로 보여준다 — 못 읽는 아이도 상황을 안다

### 표정 12종 (쿼카 커플 각각)

| | | | |
|---|---|---|---|
| 😊 기뻐 | 😆 신나 | 😲 놀라워 | 🤔 궁금해 |
| 😌 편안해 | 😤 뿌듯해 | 🥹 고마워 | 😑 심심해 |
| 🥺 서운해 | 😨 무서워 | 😢 슬퍼 | 😠 화나 |

쿼카는 **입꼬리가 올라간 얼굴**이라 원래 표정 변화가 적다. 그게 오히려 특징이다 —
**눈과 눈썹, 귀 각도로만** 12종을 만든다. 픽셀 38px에서도 구분된다.

리더 12 + 파트너 12 = **24컷.** 이건 기존 캐릭터 에셋을 잘라 만들 수 있다.

## 4. 난이도 — 8세부터 중학생까지

한 게임으로 초1과 중3을 다 받으려면 **길을 나누는 수밖에 없다.**
처음 켤 때 한 번 고르고, 설정에서 언제든 바꾼다.

| 단계 | 대상 | 단어 | 마법 거는 법 |
|---|---|---|---|
| 🌱 **씨앗** | 초1~2 | 3~4자 (sun, cat, big) | **그림 3개 중 고르기.** 철자는 눈으로만 |
| 🌿 **새싹** | 초3~4 | 4~6자 (water, jump, cloud) | 빈칸 1~2개 채우기 |
| 🌳 **나무** | 초5~6 | 6~8자 + 반의어 (open↔close) | 철자 전부 놓기 |
| ⛰ **산** | 중1~3 | 숙어·문법 (turn on, would) | **문법 마법** (아래) |

**단계를 올려도 이야기는 같다.** 같은 장면을 같은 순서로 지나간다.
형이 하던 걸 동생이 씨앗 단계로 똑같이 할 수 있어야 한다.

## 5. 문법을 마법으로 — 중학생용

여기가 이 기획에서 제일 재밌는 부분이고, 마법천자문의 **부수 조합**에 정확히 대응한다.

| 문법 | 마법 | 예 |
|---|---|---|
| **-s (복수)** | 🪞 분신 | `rock` → `rocks` 돌 하나가 여러 개 |
| **-ed (과거)** | ⏪ 되돌리기 | `break` → `broke` 깨진 다리가 되돌아온다 |
| **un-** | 🔄 반대로 | `lock` → `unlock` 잠긴 문이 열린다 |
| **re-** | 🔁 다시 | `build` → `rebuild` 무너진 것을 다시 |
| **-er (비교)** | 📈 더 | `big` → `bigger` 발판이 더 커진다 |
| **-less** | 🕳 없애기 | `fear` → `fearless` 무서움이 사라진다 |
| **will** | ⏩ 앞당기기 | 아직 안 온 다리를 미리 부른다 |

**접사 타일을 단어 타일에 붙이는** 조작이다. 손으로 붙이면 화면에서 실제로 그 일이 일어난다.
문법을 설명하지 않고 **보여준다.** 이게 학습지와 다른 점이다.

## 6. 도감 — 배운 단어가 쌓인다

교육의 뼈대다. 기존 도감 구조(`_auto_souvenir`)를 그대로 쓴다.

> 🔥 **fire** [파이어]
> 불
> *얼음 벽을 녹였어요* ← 어디서 썼는지 함께 적힌다

- **쓴 적 있는 단어만** 들어간다. 외운 단어가 아니라 **써 본 단어**를 모은다
- 도감에서 누르면 그때 장면이 짧게 다시 나온다 (문맥으로 기억)
- 목표: 씨앗 100단어 / 새싹 200 / 나무 300 / 산 400 + 문법 마법 20

교육과정 기준 낱말(초등 800단어)에서 고른다. **어려운 단어를 넣지 않는다.**

## 7. 저장 — 자동, 그리고 초기화

> 이 절은 **이미 구현했다** (아래 "지금 반영한 것" 참고).

- **자동 저장.** 저장 버튼은 안 만든다. 아이가 저장을 챙기게 하면 안 된다
- 저장 시점: 한 단어 풀 때마다 · 장면이 넘어갈 때 · **앱을 끄거나 물러날 때**
- **설정 → 기록 초기화.** 두 번 눌러야 지워진다 (실수 방지)

## 12. 정직하게 — 위험한 곳

**(1) "마법천자문"은 상표다.**
컨셉(한자→마법)은 아이디어라 따라 해도 되지만, **이름·캐릭터·장면 구성을 닮게 만들면 안 된다.**
손오공 같은 주인공, 같은 배틀 구도, 비슷한 로고를 쓰지 않는다.
우리는 쿼카 커플이고 **싸움이 아니라 길 열기**다 — 이 차이를 분명히 유지해야 한다.

**(2) 초1과 중3을 한 게임에 담는 건 원래 무리다.**
4단계로 나눴지만, 실제로는 **이야기가 어느 쪽에 맞느냐**가 갈린다.
중3이 "오늘도 심심해요" 톤을 견딜지 의문이다.
→ 제안: **이야기 톤은 초등 고학년(5~6학년)에 맞춘다.** 아래는 단계로 받고,
위는 문법 마법의 재미로 잡는다. 모두를 만족시키려다 아무도 못 잡는 게 제일 위험하다.

**(3) 단어 400개 × 장면을 손으로 짜야 한다.**
지금까지 기획 중 **작업량이 압도적으로 제일 크다.**
단어만 나열하는 건 쉽지만, "그 단어를 써야만 풀리는 장면"을 400개 만드는 건 다른 일이다.
→ 장면 **틀 12종**을 만들고 단어를 갈아 끼우는 식으로 간다. 그래도 큰 작업이다.

**(4) 표정 컷 24장이 필요하다.**
비용 드는 이미지 생성은 안 쓴다. 기존 쿼카 에셋을 잘라 **눈·눈썹·귀만 픽셀로 고쳐** 만든다.
PIL로 처리 가능하다 (무료).

**(5) 영어 발음을 어떻게 들려주나.**
단어 게임인데 소리가 없으면 반쪽이다. 유료 TTS는 규칙상 못 쓴다.
→ 1단계는 **한글 발음 표기만** (`[파이어]`). 2단계에서 단어 400개 녹음.
`redesign-kids.md` 6절과 같은 문제이고, 같은 방식으로 미룬다.

**(6) 이번엔 정말 다시 만드는 것이다.**
앞선 기획들은 코어 루프(여행)를 남겼는데, 이번엔 그것도 지운다.
남는 건 저장·설정·자동갱신·캐릭터·픽셀 파이프라인 정도다.

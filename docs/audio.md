# 효과음 (코드 합성)

외부 사운드 파일을 쓰지 않는다. `AudioStreamWAV` 에 파형을 직접 계산해 넣는다.
`scripts/systems/audio_manager.gd` (오토로드 `AudioManager`)

## 소리 목록

| 호출 | 소리 | 쓰이는 곳 |
|---|---|---|
| `footstep()` | 낮고 짧은 툭 | 플레이어 걷기 |
| `shutter()` | 찰칵 (2단 클릭 + 고음) | 첫 사진 |
| `ui_click()` | 짧은 클릭 | 소식 열기, 기념품 읽기 |
| `ui_confirm()` | 두 음 상승 | 상호작용, 여행 출발 |
| `message_arrive()` | 부드러운 3음 종소리 | 여행 중 소식 도착 |
| `souvenir_get()` | 반짝임 | 기념품 획득 |

## 원리

```gdscript
# 22050Hz, 16bit 모노. t 를 받아 -1.0~1.0 을 돌려주는 함수만 있으면 된다.
func _click_wave(t: float, dur: float) -> float:
	return sin(TAU * 880.0 * t) * exp(-t * 90.0) * 0.8
```

- 앞뒤 64샘플 페이드로 클릭 노이즈를 없앤다
- 한 번 만든 파형은 캐시한다
- 8개 플레이어 풀을 돌려써서 소리가 겹쳐도 끊기지 않는다
- 발소리는 재생마다 피치를 랜덤하게 흔들어 단조롭지 않게 한다

설정 화면의 효과음 슬라이더가 `AudioManager.set_sfx_volume()` 로 연결된다.

# 배경음악 (코드 합성)

효과음과 같은 방식. 외부 음원 파일이 없다.

| 곡 | 쓰이는 곳 | 길이 | 화음 진행 |
|---|---|---|---|
| `menu` | 타이틀 | 24초 | I – IV – V – I |
| `episode0` | 0편 전체 | 26초 | I – vi – IV – V |
| `travel` | 여행 허브 | 22초 | I – V – IV – I |
| `room` | 기념품 방 | 20초 | I – IV – I – V |

```gdscript
AudioManager.play_bgm("travel")   # 같은 곡이면 무시, 다르면 1.6초 크로스페이드
AudioManager.stop_bgm()
```

## 밝게 유지하는 규칙

- 화음은 **전부 장3도(+4반음)를 품은 메이저 계열**
- 음계는 **장5음계** `[0, 2, 4, 7, 9, 12, 14, 16]`
  (단5음계 `[0,3,5,7,10]` 를 쓰면 곧바로 슬퍼진다 — 실제로 첫 버전이 그랬다)
- 멜로디는 마디당 2~3음으로 자주 움직이고, 감쇠를 약하게 해서 쓸쓸함을 줄인다
- 위쪽 음을 45% 확률로 한 단계 올려 골라 산뜻하게 한다

## 이음매 없는 루프

모든 주파수를 **루프 길이 안에서 정수 번 진동하도록** 보정한다.

```gdscript
func _loopable(f: float, dur: float) -> float:
	return maxf(1.0, round(f * dur)) / dur
```

이러면 끝과 시작이 정확히 이어져 반복해도 툭 끊기는 소리가 없다.
(테스트에서 |끝−시작| 차이가 32767 중 600~800 이하로 유지되는지 확인한다)

## 끊김 방지

합성에 곡당 1.4~2.1초가 걸리므로 `WorkerThreadPool` 로 백그라운드에서 만든다.
만드는 사이에 다른 씬으로 넘어가면 그 곡은 버린다.

설정 화면의 배경음 슬라이더가 `AudioManager.set_bgm_volume()` 로 연결된다.

## 퍼블릭 도메인 민요 편곡

호주 전래곡을 편곡해 쓴다. 쿼카가 호주 동물이라 세계관과도 맞는다.
**선율만 기악으로** 쓰고 가사는 넣지 않는다 (가사는 별개 저작물일 수 있으므로).

| 곡 | 출처 | 저작권 |
|---|---|---|
| `matilda` | Waltzing Matilda | 작사 Paterson(†1941) → 1991 만료<br>작곡 Macpherson(†1936) → 1986 만료 |
| `shears` | Click Go the Shears | 호주 전래(작자 미상) |

Waltzing Matilda 는 떠돌이(swagman)의 여행 이야기라 타이틀 화면에 쓴다.

### 저작권 확인 기준

- **한국**: 1962-12-31 이전 사망 → 사후 50년 (70년 연장 소급 안 됨) / 이후 사망 → 사후 70년
- 확인하지 않은 곡은 쓰지 않는다

참고로 검토했다가 **제외한** 곡:

| 곡 | 사유 |
|---|---|
| Kookaburra Sits in the Old Gum Tree | Marion Sinclair †1988 — 보호 중 (실제 소송 사례 있음) |
| 반달 (윤극영 †1988) | 2058년까지 |
| 산토끼 (이일래 †1979) | 2049년까지 |
| 가고파 (김동진 †2009) | 2080년까지 |

홍난파(†1941) 곡(고향의 봄·봉선화)은 1991년 만료라 사용 가능하다.
쓰고 싶으면 `PD_MELODIES` 에 선율을 추가하면 된다.

### 선율 수정 방법

`PD_MELODIES` 의 `notes` 는 `[반음, 박]` 배열이다. 반음은 으뜸음 기준,
박은 4분음표 = 1.0, `REST` 는 쉼표.

```gdscript
[7, 0.5], [7, 0.5], [12, 0.5], ...   # 솔 솔 도' ...
```

음이 틀리면 이 숫자만 고치면 된다. 화음·음색은 그대로 유지된다.

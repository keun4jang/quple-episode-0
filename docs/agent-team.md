# 쿼플 에이전트 팀

게임 스튜디오의 직군을 그대로 옮긴 20명 구성. 정의는 `.claude/agents/*.md` 에 있다.

## 조직도

```
studio-director  (총괄 — 무엇부터 할지 정한다)
│
├─ design-lead   (기획팀장)
│   ├─ system-balance   수치·밸런스·확률
│   ├─ narrative        이야기·대사·여행지 문구
│   └─ ux-flow          화면 흐름·막다른 길
│
├─ art-lead      (아트팀장)
│   ├─ art-layout       배치·잘림·겹침·종횡비
│   ├─ art-color        색·조명·시간대 무드
│   ├─ art-motion       움직임·전환·손맛
│   └─ art-3d           실루엣·모델·베벨·텍스처
│
├─ eng-lead      (개발팀장)
│   ├─ eng-performance  프레임·메모리·모바일 발열
│   ├─ eng-build        APK·자동 갱신·버전
│   └─ eng-refactor     중복·죽은 코드·읽기 쉬움
│
├─ qa-lead       (QA팀장)
│   ├─ qa-playthrough   처음부터 끝까지 실제 플레이
│   └─ qa-device        해상도·기기·안드로이드 동작
│
├─ audio         (사운드)
├─ liveops       (운영 — 배포가 실제로 도달하는지)
└─ localization  (한국어 품질·다국어 준비)
```

## 팀장이 따로 있는 이유

팀장은 **고치지 않는다.** 전체를 훑어 **무엇이 문제인지 가리고 우선순위를 정한다.**
세부는 팀원이 판다. 팀장이 픽셀을 파기 시작하면 전체를 보는 사람이 없어진다.

**에이전트는 다른 에이전트를 부르지 못한다.** 그래서 팀장의 보고서가 곧 팀원에게 넘길
배분표가 되고, 실제 fan-out 은 메인 세션이 한다.

## 부르는 법

```
Task 도구 subagent_type 에 이름을 그대로 넣는다: art-lead, qa-playthrough …
```

정의 파일은 **세션 시작 시 읽힌다.** 새로 만들거나 고친 직후에는 그 세션에서 이름으로
못 부를 수 있다. 그럴 때는 `general-purpose` 로 띄우고 정의 파일을 읽으라고 지시하면 된다.

## 공통 규칙

전원이 이 세 문서를 먼저 읽는다.

| 문서 | 내용 |
|---|---|
| `docs/agent-team.md` | 이 문서. 팀 구조 |
| `docs/design-rules.md` | 디자인·기술 기준, 실제로 났던 사고 목록 |
| `CLAUDE.md` | 프로젝트 규칙 (이름·폰트·비용 승인) |

그리고 전원이 같은 태도를 따른다.

- **없는 문제를 지어내지 않는다.** 괜찮으면 괜찮다고 한다
- 판단이 안 서면 "판단 불가"라고 쓰고 왜 그런지 적는다
- 추측을 결론처럼 쓰지 않는다
- 측정할 수 있는 것은 측정한다. 화면은 렌더해서 **눈으로 본다**

## 동시에 돌릴 때

여럿이 함께 Godot 을 실행하면 `.godot` 캐시가 충돌해 렌더가 실패할 수 있다.
임시 프로브는 `tests/_<이름>.gd` 로 서로 겹치지 않게 만든다 (`tests/_*` 는 gitignore).
출력이 아예 없으면 잠깐 기다렸다 한 번만 재시도한다.

## 왜 이 구성인가

실제 캐주얼·힐링 모바일 스튜디오의 현실적 규모가 6~10명이고, 그보다 커지면
소통 비용이 개발 속도를 잡아먹는다. 여기서 20명으로 나눈 건 사람이 아니라
**관점**이기 때문이다. 한 관점이 한 가지만 보면 놓치는 게 줄어든다.

이 프로젝트에서 반복된 교훈이 그 근거다.

- 테스트 429개가 통과하는 동안 게임이 플레이 불가능했다 → `qa-playthrough`
- 터치 테스트 17개가 통과하는 동안 폰에서 아무것도 안 눌렸다 → `qa-device`
- 글자 크기를 씬 파일만 고치고 코드 라벨을 놓쳤다 → `art-layout`, `localization`
- 실내가 전부 파랬는데 아무도 그걸 "문제"라고 부르지 않았다 → `art-color`
- 만들어 둔 메인 화면을 아무도 못 봤다 (시작 씬이 아니었다) → `ux-flow`

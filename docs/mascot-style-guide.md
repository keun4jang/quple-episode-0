# 퀴풀 마스코트 스타일 가이드 v1.0

## 1. 캐릭터 역할

| | 퀴카 A (리더) | 퀴카 B (파트너) |
|---|---|---|
| **역할** | 여행을 이끄는 밝은 리더 | 여행을 기록하는 다정한 파트너 |
| **성격** | 호기심 많고 활발함 | 부드럽고 귀여움 |
| **파일** | `assets/mascots/quika-leader.png` | `assets/mascots/quika-partner.png` |
| **커플 합본** | `assets/mascots/quika-couple-hero.png` | |

---

## 2. 외형 특징

### 공통
- 몸통: 둥근 원형 (toy/clay 느낌)
- 귀: 둥글고 통통한 귀, 안쪽 복숭아색
- 눈: 큰 반짝이는 눈, 흰자 + 어두운 홍채 + 동공 + 하이라이트 2개
- 코: 작은 타원형, 상단 하이라이트 포인트
- 입 주변: 크림색 muzzle 영역
- 볼: 부드러운 핑크/살구 볼터치
- 배: 밝은 크림 털 패치
- 손끝/발바닥: 크림색

### 퀴카 A (리더)
- 털 색상: 따뜻한 캐러멜 (#B98246 / rgb 185,130,70)
- 볼터치: 살구 핑크
- 소품:
  - 초록 여행 캡 (+ 행성 배지)
  - 파란 백팩 (왼쪽)
  - 검은 카메라 (가슴 앞)

### 퀴카 B (파트너)
- 털 색상: 밝은 허니크림 (#CDA564 / rgb 205,165,100)
- 볼터치: 핑크
- 소품:
  - 핑크 스카프 (목)
  - 황갈색 크로스백 (오른쪽)
  - 노란 티켓 (왼손)

## 4. 금지 요소

- ❌ 머리 위 안테나/더듬이 형태의 털 뭉치
- ❌ 날카로운 형태의 귀
- ❌ 너무 사실적인 동물 눈 (무서운 느낌)
- ❌ 기괴하거나 불안한 표정
- ❌ 너무 평면적인 아이콘 스타일
- ❌ 유료 폰트 / 유료 에셋 / 외부 이미지 사용
- ❌ 실존 브랜드 노출

## 5. 재사용 규칙

### 에셋 파일 구조
```
assets/
  mascots/
    quika-leader.png        # 리더 단독 (500×600px)
    quika-partner.png       # 파트너 단독 (500×600px)
    quika-couple-hero.png   # 커플 합본 (900×600px)
    mascot-manifest.json    # 에셋 메타데이터
  splash/
    splash-poster-no-text.png  # 스플래시 포스터 배경
```

### 크기별 가이드
| 용도 | 권장 크기 | 최소 크기 |
|---|---|---|
| 스플래시 히어로 | 300px+ | 150px |
| 게임 내 NPC | 120px | 64px |
| 아이콘/아바타 | 64px | 32px |
| 알림/뱃지 | 32px | 16px |

### 32px에서도 구분되어야 할 실루엣 요소
- A: 초록 캡 실루엣 + 둥근 귀
- B: 핑크 스카프 + 둥근 귀

## 6. 표정/포즈 확장 계획

### 표정 목록 (추후 제작)
| ID | 이름 | 설명 | 우선순위 |
|---|---|---|---|
| `happy` | 기쁨 | 눈이 초승달, 볼터치 강화 | High |
| `excited` | 흥분 | 눈 크게, 입 크게 열림 | High |
| `shy` | 수줍음 | 눈 피하기, 볼 빨개짐 | Medium |
| `sad` | 슬픔 | 눈썹 처짐, 눈물 | Medium |
| `surprised` | 놀람 | 눈 동그라미, 입 O형 | Medium |
| `sleepy` | 졸림 | 반쪽 눈, ZZZ | Low |
| `wink` | 윙크 | 한쪽 눈 찡긋 | Low |

# 힐링 설계 — 마이 오아시스 · Journey 에서 가져온 것

20~30대 힐링 니즈에 맞추기 위해 두 게임을 벤치마크해 적용한 내용.

## 1. 숫자를 지운다 (Journey)

여행 중 화면에서 **남은 시간·진행바를 없앴다.** 대신 **하늘빛과 해의 위치**가 진행도를 말한다.

- 출발 = 새벽(남보라) → 중간 = 낮(하늘색) → 도착 임박 = 노을(주황)
- 해는 왼쪽에서 오른쪽으로, 가운데서 가장 높이 뜬다
- 숫자가 궁금하면 **D 를 누르고 있는 동안만** 남은 시간이 보인다

> 숫자를 보면 '기다리는 일'이 되고, 하늘을 보면 '지켜보는 일'이 된다.

## 2. 도착은 정산이 아니라 엽서 (마이 오아시스)

기존: 텍스트 나열 → 지금: **폴라로이드 엽서가 살짝 기울어져 내려앉는다.**

- 사진은 여행지 색조로 **코드가 그린다** (하늘 그러데이션 + 산 실루엣 + 해/달 + 쿼카 둘)
- 같은 곳은 항상 같은 그림 (dest_id 로 시드 고정)
- `scripts/travel/postcard_export.gd` 로 PNG 저장도 된다 (480×600)

## 3. 색조 하나로 225곳을 구분한다 (Journey)

3D 에셋을 225개 만들 수 없으므로 **빛과 색만 바꾼다.**
`scripts/travel/palette.gd`

| 구분 | 팔레트 |
|---|---|
| 막 | 국내 · 해외 · 우주 · 다른 차원 |
| 대륙 | 아시아 · 유럽 · 아프리카 · 아메리카 · 오세아니아 |

**쿼카 스카프의 산호색(#FF6F61)은 어느 배경 팔레트에도 쓰지 않는다.**
그 색이 캐릭터에만 있어야 작은 화면에서 시선이 캐릭터로 간다. (테스트가 자동 검증)

## 4. 아무 일도 없는 날 (Journey 의 여백)

약 **22% 확률**로 사진 없이 한 줄만 오는 날이 있다.

> *"오늘은 그냥 걸었다."*
> *"사진을 찍는 걸 잊었다. 그만큼 좋았다는 뜻이겠지."*

매번 이벤트가 터지면 이벤트가 무의미해진다. 빈 날이 다음 사진을 특별하게 만든다.

## 5. 수치가 아니라 '함께 배우는 것' (마이 오아시스)

능력치 대신 **둘이 여행하며 익히는 것**으로 부른다. 다녀온 곳 수에 따라 8개가 열린다.

| 이름 | 설명 |
|---|---|
| 천천히 걷기 | 서두르지 않아도 도착은 한다 |
| 길 잃어도 괜찮기 | 예정에 없던 곳이 제일 기억에 남는다 |
| 서로 사진 찍어주기 | 풍경보다 사람이 남는다 |
| 아무 계획 없는 하루 | 비워둔 날이 여행을 살린다 |

`%`, `+`, `증가` 같은 표현을 쓰지 않는다. (테스트가 자동 검증)

## 6. 장소마다 다른 공기 (Journey 의 사운드)

BGM과 별개로 **주변 소리**를 코드로 합성한다. BGM보다 훨씬 작게(-24dB) 깔린다.

| 소리 | 합성 방식 | 쓰이는 곳 |
|---|---|---|
| `wave` | 저역통과 노이즈 + 느린 출렁임 | 부산·제주·강릉·오세아니아 |
| `wind` | 대역통과 노이즈 + 불규칙 세기 | 국내·해외 |
| `rain` | 고역 노이즈 + 빗방울 알갱이 | (예비) |
| `space` | 41~68Hz 사인 맥놀이 | 우주·다른 차원 |
| `room` | 거의 무음에 가까운 방 소리 | 기념품 방 |

전부 8~12초 루프이며 이음매가 튀지 않게 크로스페이드 처리했다.

## 7. 여행 기록 화면 (숫자 최소화)

`📊 여행 기록` 버튼으로 연다. 225곳을 **점 하나씩** 그려 다녀온 곳만 밝게 표시한다.

- 막별 진행은 가로 막대. 잠긴 막은 🔒 로 흐리게
- 가장 자주 간 곳, 모은 기록 수, **조용한 하루가 몇 번이었는지**
- 아래에 지금까지 익힌 습관을 칩으로

점 그림은 노드 225개 대신 `Control._draw()` 로 직접 그린다.

## 8. 엽서 내보내기

앨범의 각 기록 옆 `🖼` 로 **480×600 PNG** 를 저장한다.
`user://postcards/` 에 저장되고 화면에 경로를 알려준다.

## 9. 방이 진행도를 말한다

기념품 방의 조명이 전체 진행도에 따라 변한다.

| 진행 | 분위기 |
|---|---|
| 0~25% | 밤. 창밖이 어둡고 램프만 따뜻하다 |
| 25~65% | 새벽~아침. 창으로 푸른빛이 든다 |
| 65~100% | 낮~노을. 방 전체가 따뜻해진다 |

별은 밤일수록 많이 보이고, **다른 차원을 다녀왔다면 창밖에 오로라**가 뜬다.
들어올 때 진행도를 정서적으로 한 줄 알려준다 — *"창밖이 조금 밝아졌어요."*

## 10. 앱 아이콘

`tools/icon/gen_icon.py` 로 코드 생성. 512/256/128/64px.
쿼카 얼굴 + **산호색 스카프**(게임 강조색과 동일). 4배 슈퍼샘플링으로 안티에일리어싱.

## 하지 않기로 한 것

- 스트릭·출석 압박
- 광고
- 친밀도·호감도 게이지
- 사진 도감 그리드 (기념품 방이 이미 그 역할)

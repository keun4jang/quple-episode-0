# 쿼플 코어 루프

## 한 문장

> **앱을 끄면 쿼카 커플이 여행을 다녀오고, 다시 켜면 그들이 찍어온 사진과 일기를 확인한다.**

플레이어는 조종하지 않고 **들여다본다**. 츠키 어드벤처(730만 DL)가 검증한 구조이며,
짧은 체크인(1~3분)만으로 정서적 리텐션이 생기고 실시간 조작이 없어 1인 개발에 적합하다.

## 3단계

| 단계 | 화면 | 하는 일 |
|---|---|---|
| ① 보내기 | `IDLE` | 여행지 카드 3장 중 선택 → 출발 |
| ② 기다리기 | `TRAVELING` | **앱을 꺼도 진행됨.** 남은 시간·진행바 표시 |
| ③ 확인하기 | `ARRIVED` → 기념품 | 사진 1장 + 일기 1줄을 받아 앨범에 저장 |

## 오프라인 진행의 원리

`Time.get_unix_time_from_system()` 으로 **실제 시각**을 기록한다.

```gdscript
trip = { "dest_id": id, "depart_at": now, "arrive_at": now + duration }
func has_arrived() -> bool: return _now() >= trip.arrive_at
```

앱이 떠 있든 꺼져 있든 도착 판정은 동일하다. 타이머를 돌리지 않으므로 배터리도 쓰지 않는다.
저장 파일에 `arrive_at` 이 그대로 들어가므로 앱을 강제 종료해도 복원된다. (테스트 [7] 항목)

## 여행지 (해금 조건 있음)

| ID | 이름 | 소요 | 해금 조건 | 기념품 |
|---|---|---|---|---|
| `seoul` | 서울 | 30분 | 처음부터 열림 | 첫 골목 / 한강의 오후 / 야경 |
| `paris` | 파리 | 2시간 | **서울 3회** | 낯선 아침 / 탑 아래에서 / 비 오는 골목 |
| `moon` | 달 | 6시간 | **파리 2회** | 조용한 곳 / 지구를 보다 / 발자국 |

재방문하면 `visit_count` 에 따라 **다음 기념품**이 열리고, 다 보면 순환한다.

### 개발 중 빠른 확인

```bash
QUPLE_FAST_TRAVEL=1 godot --path .    # 20 / 40 / 60초로 단축
```

## 0편에서 챙긴 물건이 여행에 반영된다

| 물건 | 없을 때 |
|---|---|
| 📷 카메라 | 사진이 남지 않는다 (`[ 사진 없음 ]`) |
| 📓 수첩 | 일기가 "기억으로만 남았다" 로 바뀐다 |
| 🎒 가방 | (표시용) |

0편을 건너뛴 경우에는 제한하지 않는다.

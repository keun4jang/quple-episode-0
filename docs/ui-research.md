# 타 게임 UI 비교 — 쿼플에 무엇이 필요한가

옆에서 보는 아기자기한 모바일 게임들과 화면을 나란히 놓고, 그들이 다 갖고
있는데 우리에게 없는 것을 골랐다. 기준은 "예쁜가" 가 아니라 **"없으면
사용자가 헤매는가"** 다.

## 비교 대상과 그들의 공통 문법

| 게임 | 왼손 | 오른손 | 왼쪽 위 | 오른쪽 위 | 그 밖에 |
|---|---|---|---|---|---|
| 메이플스토리M | 조이스틱 | 큰 공격 + 위성 스킬들 | 캐릭터 상태 | 메뉴·설정 | 퀘스트 트래커, 미니맵 |
| 모여봐요 동물의 숲 | 터치 이동 | 맥락 버튼 하나 | 목표/의뢰 | 메뉴 | 수집 카운터 |
| Tsuki Adventure | (방치형) | 맥락 버튼 | 소지금 | 설정 | 일기·앨범 |
| 스타듀밸리 모바일 | 조이스틱 | 맥락 버튼 | 시계·날짜 | 메뉴 | 퀘스트 목록 |

넷이 겹치는 것: **① 지금 뭘 해야 하는지가 늘 화면에 있다**
**② 모으는 중이면 몇 개째인지 보인다** **③ 오른손 큰 버튼은 맥락에 따라
바뀌는 "하기" 버튼이다** **④ 설정은 오른쪽 위 구석이다**

## 우리 상태와 조치

| 항목 | 조치 |
|---|---|
| 조이스틱 + 큰 선택 버튼 + 점프 위성 | ✓ 이미 적용 (v0.1.43) |
| 설정 오른쪽 위 | ✓ 이미 적용 (v0.1.43) |
| **목표 트래커** | ✗ 없었다 → **왼쪽 위에 추가.** 대사를 놓치면 헤맬 길밖에 없었다 |
| **수집 카운터** | ✗ 없었다 → **목표 아래 📷📓🎒 추가.** 챙기는 동안에만 뜬다 |
| 미니맵 | 안 넣는다. 맵이 한 줄이라 길을 잃을 수 없다 |
| 체력/전투 UI | 없음. 우리 게임에 전투가 없다 — 공격 자리가 "선택" 인 이유 |

## 일부러 안 따라간 것

메이플의 화면은 버튼 열몇 개가 상시로 떠 있다. 그건 스킬이 열몇 개라서다.
우리 동사는 걷기·점프·선택 셋뿐이므로, 버튼도 셋을 넘기지 않는다.
비교 조사의 결론이 "다 베끼자" 가 되면 안 된다 — **그 게임에 그 UI 가 있는
이유**가 우리에게도 있는지가 기준이다.

# 힐링 게임에서 가져올 것

> **주의**: 이 문서는 실제 게임을 다시 플레이하며 확인한 것이 아니라, 알고 있는 범위에서
> 정리한 것이다. 세부 수치나 최근 버전의 동작은 다를 수 있다. 여기 적힌 것을
> "그 게임이 이렇게 한다" 는 사실로 인용하지 말고, **우리가 시도해 볼 방향**으로만 쓴다.
> 확인이 필요하면 실제 화면을 보고 판단한다.

## 참고한 게임과 그 게임의 핵심

| 게임 | 이 게임이 잘하는 것 |
|---|---|
| 마이 오아시스 | 화면 아무 데나 만지면 반응한다. 아무것도 안 해도 자란다 |
| Journey | 목적지(먼 산)가 늘 화면에 보인다. 이동 자체가 즐겁다. 말이 거의 없다 |
| Alto's Odyssey | 시간대와 날씨가 계속 변한다. 실패가 없는 모드가 따로 있다 |
| Monument Valley | 조작하는 동작 자체가 애니메이션이다 |
| 동물의 숲 | 실시간으로 흐른다. 안 하는 동안 편지와 선물이 쌓인다 |

## 공통 원리 여덟 가지

**1. 손대면 반응한다**
힐링 게임의 기본 단위는 "만졌더니 뭔가 일어났다" 이다. 소리든 파티클이든 흔들림이든.
반응 없는 터치가 반복되면 화면이 죽은 것으로 느껴진다.

**2. 실패가 없다**
죽지 않고, 잃지 않고, 시간에 쫓기지 않는다. 긴장을 만드는 장치를 넣지 않는다.

**3. 기다림이 보상이 된다**
꺼 놓은 동안 무언가 쌓여 있어야 다시 켠다. 빈손으로 돌아오면 다음이 없다.

**4. 목적지가 보인다**
Journey 는 항상 먼 산이 화면에 있다. 길을 몰라 헤매는 것과 천천히 가는 것은 다르다.

**5. 세계가 흐른다**
시간대·날씨·빛이 계속 바뀐다. 같은 장소를 다시 봐도 다르게 보인다.

**6. 말이 적다**
설명하지 않고 보여 준다. 긴 텍스트는 힐링의 리듬을 끊는다.

**7. 모은 것이 쌓여 보인다**
숫자가 아니라 **눈에 보이는 형태**로 쌓여야 한다. 방에 놓인 기념품, 앨범의 사진.

**8. 소리가 절반이다**
자연음과 부드러운 악기. 조작음 하나하나가 촉감을 만든다.

## 쿼플에 대입하면

### 이미 있는 것

| 원리 | 우리 구현 |
|---|---|
| 실패 없음 | 죽음·시간 압박·벌칙이 없다 |
| 기다림이 보상 | 실제 시각으로 여행이 진행되고 사진·일기·기념품이 쌓인다 |
| 목적지가 보인다 | 방향 표시(화살표 + 거리) |
| 세계가 흐른다 | 시간대별 무드 6구간 |
| 모은 것이 쌓임 | 기념품 방, 앨범 |
| 소리 | 절차적 피아노 BGM, 앰비언트 5종 |

### 없는 것 — 여기가 다음 작업이다

**A. 손대면 반응하지 않는다** (제일 큼)
지금은 정해진 버튼과 상호작용 지점 말고는 화면을 아무리 만져도 아무 일도 없다.
마이 오아시스의 핵심이 정확히 이것이고, 우리에게 통째로 빠져 있다.

**B. 효과음이 6개뿐이다**
발소리·셔터·클릭·확인·차임·반짝임. 문 여는 소리, 물건 집는 소리, 앉는 소리,
바람이 스치는 소리가 없다. 소리가 절반이라면 우리는 절반의 절반만 있다.

**C. 돌아왔을 때의 연출이 약하다**
여행이 끝났는데 조용히 목록에 추가될 뿐이다. "다녀왔어요" 가 사건처럼 느껴져야 한다.

**D. 이동 자체가 즐겁지 않다**
Journey 는 모래를 미끄러지는 감각만으로 재미를 만든다.
우리는 걷고 네 발로 뛸 수 있지만, 걸을 때 발밑에서 아무 일도 일어나지 않는다.

**E. 텍스트가 많다**
설명하는 대사가 많고, 보여 주는 연출이 적다.

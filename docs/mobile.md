# 폰에서 만지는 것

탑다운 여행 하나만 남은 지금, 화면을 만지는 방법은 셋뿐이다.

| | 무엇 | 어디 |
|---|---|---|
| 한 손가락 | 누른 자리를 중심으로 **걷는다** | `scripts/journey/journey_touch.gd` |
| 두 손가락 | 오므리면 **확대·축소** | `scripts/journey/journey_camera.gd` |
| 탭 | 말 걸기 · 줍기 · 자기 · 떠나기 | `scripts/journey/place.gd` |

화면에 고정된 조이스틱을 안 그린다. 엄지 위치는 사람마다 다르다.

## 손가락을 갈아 낄 때

두 손가락이 닿는 순간 걷기를 놓고, **다 뗄 때까지 안 푼다**
(`journey_touch.gd` 의 `_pinch_lock`).

예전엔 손가락 **수**만 셌다. 그래서 두 손가락 중 먼저 댄 쪽을 떼면
숫자가 0 으로 돌아가고, 남은 손가락은 아직 화면에 있는데 걷기가 다시
열렸다 — 화면을 오므리는 중에 쿼카가 걸어갔다.

## 버튼은 걷는 손가락을 안 탄다

`TextureButton` 은 **터치에서 흉내낸 마우스**로만 눌리는데, 엔진은 그
흉내를 첫 번째 손가락 하나에만 건다. 그 손가락은 걷기가 쓴다. 그래서
걸으면서 셔터를 누르면 아무 일도 안 일어났다.

지금은 걷기 쪽이 손가락을 집기 전에 `JourneyHud.try_touch()` 로 먼저
물어본다.

## 배율

**정수 배율만 쓴다 — 2 / 3 / 4** (`STEPS`). 2.5배에서는 원본 한 픽셀이
화면 2.5픽셀이 되어 어떤 픽셀은 두 칸, 어떤 픽셀은 세 칸을 차지한다.
격자가 울퉁불퉁해지고 걸어 다니면 지글거린다.

**지도보다 넓게는 안 보여 준다.** 지도 밖에는 아무것도 없어서 엔진
기본 회색이 그대로 드러난다. 초광각 폰(2400x1080)에서 2배로 축소하면
보이는 세계가 가로 800px 인데 가장 큰 지도가 720px 이었다.
`set_bounds()` 가 그 지도에서 허용되는 가장 낮은 배율을 계산한다.

## 안전영역

`immersive_mode=true` 라 앱이 화면 전체를 받는다. 그 안에는 펀치홀·둥근
모서리·제스처 바가 같이 들어 있다. HUD 를 통째로 안전영역만큼 안쪽으로
민다 (`journey_hud.gd` 의 `_apply_safe_area`). 대화창도 아래 여백을
그만큼 띄운다.

## 뒤로가기

`scripts/systems/back_handler.gd`. 열려 있는 것을 위에서부터 하나씩 닫고,
더 닫을 게 없을 때만 "한 번 더 누르면 나가요" 를 띄운다.

닫는 순서: 설정 → 여행판 → 대화 → 배낭.

**그룹 이름을 지울 땐 여기도 같이 본다.** 한동안 이 파일이 이미 지워진
옛 UI 다섯(`stats_ui` `album_ui` `wind_note` `choice_box` `dialogue_box`)을
찾고 있었다. 아무것도 못 닫았고, 그 누름이 종료 카운터에 쌓여 배낭을
닫으려다 앱이 꺼졌다.

## 화면 방향

가로 고정이다 (`export_presets.cfg` 의 `screen/orientation`, APK 매니페스트
`userLandscape`). 세로로 들면 어떤 배율로도 지도보다 화면이 길어 빈 색이
난다 — 그래서 세로를 안 쓴다.

주의: **Android 16 부터 큰 화면(>600dp)에서 방향 고정이 무시된다.**
targetSdk 를 34 에서 올리면 태블릿에서 세로 화면이 나온다. 그때는
지도를 세로로 늘리거나 위아래를 그림으로 채워야 한다.

## 글자

**기기 폰트로 새는 글자를 쓰지 않는다.** 본문 폰트(`PoorStory.ttf`)에
없는 글자는 폰에서 네모 상자로 뜬다. 없는 것들: `▼ ● ★ ⚙ ✉ ✕ ✦ — 🏡 🎬`.

세모·점 같은 표시는 **글자 대신 직접 그린다** (`draw_colored_polygon`,
`draw_circle`). 도형은 폰트를 안 탄다.

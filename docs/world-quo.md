# 쿼플 세계 — 이름 규칙

> `docs/redesign-journey.md`(구상) · `docs/story-journey.md`(이야기)와 함께 읽는다.
> 상태: **확정 규칙.** 새 이름을 지을 때 반드시 여기를 따른다.

## 1. 쿼플은 무슨 뜻인가

> **쿼플(Quople) — 쿼카말로 "우리".**

낯선 둘이 한 끼를 나누거나, 한 길을 같이 걷거나, 말없이 같이 노을을 보면
그 순간 둘은 **쿼플**이 된다. 평생 가는 사이를 뜻하지 않는다. **잠깐 우리였던 것**을
가리키는 말이다.

그래서 이 게임의 제목은 곧 **목표**다.

혼자 떠난 쿼카가, 지나가는 인연들과 잠깐씩 쿼플이 되었다가, 또 혼자 걷는다.
엔딩에서 엽서를 넘겨 보는 장면은 **"내가 쿼플이었던 순간들"** 을 넘겨 보는 것이다.

### 게임 안에서 이 말을 어떻게 쓰나

- 설명하지 않는다. **쓰기만 한다**
- 마음 세 칸쯤에서 인연이 처음 이 말을 꺼낸다
  > 너구리: *"오늘 우리 쿼플이었네."*
- 도감 이름도 "인연"이 아니라 **쿼플첩**
- 엔딩 마지막 줄:
  > *혼자 떠났는데, 쿼플이 이만큼이었다.*

## 2. 쿼- 규칙

> **쿼카가 만든 것에는 쿼가 붙는다.**

이 세계의 문명은 쿼카가 세웠다. 그래서 **사람이 만든 것**의 이름은 전부 `쿼`로
시작한다. 다른 동물들도 그 말을 그대로 쓴다.

### 붙는 것 / 안 붙는 것

| | 예 |
|---|---|
| ✅ **먹을 것** | 쿼버거 · 쿼이스크림 · 쿼피(커피) · 쿼면 · 쿼빵 · 쿼치(김치) |
| ✅ **탈것** | 쿼스(버스) · 쿼차(기차) · 쿼배 · 쿼시(택시) |
| ✅ **가게·건물** | 쿼장(시장) · 쿼의점(편의점) · 쿼스텔(숙소) · 쿼탕(목욕탕) |
| ✅ **물건** | 쿼메라(카메라) · 쿼폰 · 쿼지도 · 쿼표(표) |
| ✅ **돈** | 쿼원 |
| ✅ **회사·기관** | 쿼카컴퍼니 · 쿼체국(우체국) |
| ❌ **자연** | 바다 · 바람 · 돌 · 파도 · 노을 · 감나무 — **원래 있던 것** |
| ❌ **몸과 마음** | 손 · 발 · 배고픔 · 그리움 · 슬픔 |
| ❌ **동작과 형용** | 걷다 · 앉다 · 차갑다 |
| ❌ **가족 호칭** | 엄마 · 아빠 · 동생 |

**자연에 안 붙이는 게 규칙의 핵심이다.** 다 붙이면 문장이 안 읽히고, 무엇보다
*"쿼카가 만든 것에만 붙는다"* 는 규칙 자체가 세계를 설명해 준다 —
**바다는 아무도 만들지 않았다.**

### 만드는 법

원래 낱말의 **첫 음절을 쿼로 갈아 끼운다.** 못 알아보면 실패다.

```
버거   → 쿼버거      ✅ 바로 안다
아이스크림 → 쿼이스크림  ✅
편의점 → 쿼의점      ✅
목욕탕 → 쿼탕        ✅
사진   → 쿼진        ❌ 뭔지 모르겠다 → 그냥 "사진"
```

**애매하면 안 붙인다.** 뜻이 먼저다.

### 한 화면에 두 개까지

말장난은 셋째부터 피곤해진다. 대사 한 줄에 하나, 한 화면에 둘을 넘기지 않는다.

> ✅ *"쿼장에서 쿼이스크림 하나 사 먹었어요."*
> ❌ *"쿼스 타고 쿼장 가서 쿼버거랑 쿼피 샀어요."*

### 하면 안 되는 것

**실제 상표를 흉내 내지 않는다.** `쿼도날드` `쿼벅스` 같은 것은 만들지 않는다.
일반 낱말에만 붙인다. 이건 취향이 아니라 **상표 문제**다.

## 3. 지명도 쿼로 — 그리고 이게 문제를 하나 푼다

여행지도 같은 규칙을 쓴다. 첫 음절을 쿼로 바꾼다.

| 실제 | 이 세계 |
|---|---|
| 강릉 | **쿼릉** |
| 경주 | **쿼주** |
| 부산 | **쿼산** |
| 서울 | **쿼울** |
| 제주 | **쿼도** (쿼주와 겹쳐서 섬을 살렸다) |
| 전주 | **쿼전** (겹침을 피해 순서를 바꿨다) |

`story-journey.md` 7절에서 걱정한 것 — **실제 지명을 쓰면 그 지역 이미지를
소비하게 된다** — 이 규칙이 그대로 풀어 준다. 쿼릉은 강릉이 떠오르지만
강릉이 아니다. 닮은 곳을 그리되 실제 그곳을 대변하지 않는다.

**고향만은 이름이 없다.** 그냥 "고향"이다. 누구의 고향이든 될 수 있게.

## 4. 1탄 — 국내

> 1탄은 **국내 여행**으로 한다. 해외·우주는 나중 이야기다.

```
  프롤로그   쿼울 — 쿼카컴퍼니를 박차고 나온다
      ↓
   1  쿼릉   바다. 등대와 백사장                 ← 첫 여행지
   2  쿼주   옛 도시. 낮은 기와지붕과 능
   3  쿼산   항구. 비탈진 골목과 시장
   4  쿼도   섬. 검은 돌담과 바람
      ↓
  🏡 고향    산골. 언제든 갈 수 있다             ← 이야기의 중심
      ↓
   엔딩      고향집 평상에서 엽서를 넘긴다
```

- 여행지 **넷 + 고향 하나.** 이게 1탄의 전부다
- 각 여행지 3~7일, 화면 6~9개 분량
- **쿼릉을 먼저 만든다** — 지금 있는 그림(등대·부두·게스트하우스·모래·바다)이
  그대로 맞는다
- 고향은 손으로 만드는 유일한 곳 (`story-journey.md` 5절)

### 여행자 재회 — 1탄의 심장

너구리 여행자는 **쿼릉에서 처음 만나고, 쿼산이나 쿼도에서 다시 만난다.**
어디서 다시 만날지는 플레이어가 어느 순서로 가느냐에 따라 달라진다.

> *"어? 너 여기 웬일이야?"*

이 한 순간이 되면 1탄은 성공이다. 안 되면 나머지는 안 만들어도 된다.

## 5. 1탄에 쓸 쿼- 낱말

지금 만들 것에 필요한 만큼만. 늘어나면 여기 추가한다.

| 어디 | 낱말 |
|---|---|
| 쿼울 | 쿼카컴퍼니 · 쿼차(기차) · 쿼울역 |
| 쿼릉 | 쿼스텔(숙소) · 쿼장(시장) · 쿼이스크림 · 쿼메라 |
| 쿼주 | 쿼체국(우체국) · 쿼빵 · 쿼표(입장권) |
| 쿼산 | 쿼배 · 쿼면 · 쿼탕(목욕탕) |
| 쿼도 | 쿼귤(귤) · 쿼스(버스) |
| 고향 | **하나도 안 쓴다** |

**고향에 쿼- 낱말을 안 쓰는 건 일부러다.** 상표도 가게도 없는 곳이라
붙일 것이 없고, 그래서 다른 데보다 조용하게 들린다.

## 6. 정직하게

**(1) 말장난은 금방 물린다.**
그래서 2절의 "한 화면에 둘까지"와 "자연에는 안 붙인다"가 규칙의 절반이다.
이걸 어기면 귀엽던 게 유치해진다.

**(2) 영어로 옮길 때가 문제다.**
`쿼-` 는 `Quo-` 로 간다 (Quoburger, Quocream, Quobus). 다만 한국어처럼
자연스럽지는 않다. 지금은 한국어만 만들고, 다국어는 그때 다시 본다.

**(3) 쿼플의 뜻을 설명하고 싶어질 것이다.**
참아야 한다. 뜻을 풀어 놓는 순간 값이 떨어진다. 인연이 한 번 쓰고,
플레이어가 알아채게 둔다.

**(4) 이름 규칙이 CLAUDE.md 와 겹친다.**
CLAUDE.md 에 요약을 넣고, 자세한 건 이 문서를 가리키게 했다.

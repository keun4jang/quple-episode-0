# 쿼플 디자인 규칙

디자인 에이전트들이 공통으로 지키는 기준. 판단이 갈릴 때 여기가 기준이다.

## 정체성

- 게임은 **쿼플**, 캐릭터는 **쿼카**. 퀴풀 / 퀴카 는 쓰지 않는다.
- 장르는 힐링. 20~30대가 자기 전에 켜는 게임이다.
- **"눈에 띄면 과한 것"** 이 이 게임의 기준이다. 강조는 언제나 한 단계 약하게.

## 색

- 파스텔. 채도 높은 원색, 순검정, 형광, 번쩍임 금지.
- **산호색(#FF6F61) 계열은 배경과 UI 에 쓰지 않는다.** 쿼카 스카프 색이다.
  배경에 같은 색이 있으면 캐릭터가 묻힌다. 이 색은 캐릭터에만 남겨 둔다.
  - 예외: 노을 지평선, 전구색, 글자 그림자처럼 **면이 아니라 빛**인 것.
- 한 화면에는 지배 색조 하나. 색이 섞이면 탁해진다.
- 색 정의 위치
  - UI: `scripts/ui/design.gd`
  - 시간대 무드: `scripts/systems/mood_palette.gd`
  - 여행지: `scripts/travel/palette.gd`

## 글자

- 하한 **30pt** (720 높이 기준). 그 아래는 폰에서 안 읽힌다.
- 눈금: 30 / 36 / 44 / 58. 그 사이 값을 새로 만들지 않는다.
- 폰트는 **항상 굵게**. 전역 테마가 처리하므로 개별 지정하지 않는다.
  크기만 `theme_override_font_sizes/font_size` 로 조절한다.
- **폰에 없는 키를 누르라고 하지 않는다.** Space, Esc, F, D 는 화면에 쓰지 않는다.
- 안내 문구가 가리키는 버튼은 **화면에 그 이름으로 실제 있어야** 한다.
  버튼 글자가 상황에 따라 바뀌면 안내도 같이 바뀌어야 한다.

## 간격과 모양

- 간격은 4의 배수만 (4 / 8 / 16 / 24 / 40).
- 모서리는 12 / 22 / 34 / 알약.
- 값은 `scripts/ui/design.gd` 에서 가져온다. 그 자리에서 숫자를 적지 않는다.

## 터치

- 가로 모드 폰이 기준. 태블릿도 본다.
- 왼쪽 = 이동, 오른쪽 = 액션. 액션은 **엄지가 닿는 아래쪽 코너**에.
- 버튼은 **둥근 모서리·노치를 피해 안쪽으로**. 화면 끝까지 쓰면 잘린다.
- 쓸 수 없는 버튼은 지우지 말고 흐리게. 사라지면 "그런 기능이 없다" 로 읽힌다.
- 열린 화면 뒤는 어둡게 깔고, 그동안 조작 UI 는 감춘다.

## 기술 제약

- 렌더러가 `gl_compatibility`. SSAO · 피사계심도 · GPUParticles 는 **없다**.
  파티클은 `CPUParticles3D` 만.
- `class_name` 을 쓰지 않는다. `.godot` 이 gitignore 라 새 클론에서 죽는다.
  `const X := preload("res://...")` 를 쓴다.
- 화면 색이나 배치를 `randf()` 로 정하지 않는다. 실행마다 달라지면 검증이 안 된다.
- 유료 에셋·API·폰트 금지. 전부 코드나 로컬 도구로 만든다.

## 자동 검사

```bash
python3 tools/check-design-tokens.py
```

눈이 필요 없는 것만 본다 — 너무 작은 글자, 금지된 색. 나머지는 사람(또는 에이전트)이 본다.

## 이 프로젝트에서 실제로 났던 디자인 사고

같은 실수를 반복하지 않으려고 적어 둔다. 전부 **테스트는 통과하는데 눈으로 보면 즉시 이상한** 것들이었다.

| 증상 | 원인 |
|---|---|
| 선택지 두 개가 겹쳐 하나만 보임 | 컨테이너가 배치하기 전에 `position` 을 읽어 트윈을 걸었다 |
| 버튼이 반만 보임 | 화면 가장자리까지 배치해서 둥근 모서리에 잘렸다 |
| 비활성 버튼이 네모로 나옴 | `disabled` 스타일박스를 안 줘서 기본 테마가 나왔다 |
| 원형 버튼이 알약이 됨 | 컨테이너 폭에 늘어났다 (`SIZE_SHRINK_END` 누락) |
| 먼지가 화면 덮는 흰 사각형 | `scale_amount` 가 안 먹었다. 크기는 메시로 정해야 했다 |
| 안내가 없는 버튼을 가리킴 | 버튼 글자는 상황별로 바뀌는데 안내 문구는 고정이었다 |
| 실내가 전부 파랑 | 실내 환경광에 밤하늘색을 썼다. 실내를 밝히는 건 전등이다 |
| 텍스처가 하나도 안 붙음 | 에디터 밖에서 만든 PNG 에 `.import` 가 없어 로드가 전부 실패했다 |

# 캐릭터 도안

3D 쿼카는 코드가 구를 쌓아 만든다. 그 숫자를 **눈대중이 아니라 여기서 재서** 정한다.

- `leader-turnaround.jpg` — 리더 삼면도 (초록 모자, 가슴 카메라)
- `partner-turnaround.jpg` — 파트너 삼면도 (분홍 목도리, 옆구리 가방)
- `expressions.jpg` — 표정 8종

## 여기서 잰 값

정면도 전체 높이를 1로 놓고 잰 것이다.

| 잰 것 | 도안 | 반영 |
|---|---|---|
| 머리폭 / 몸통폭 | **0.81** | `HeadPivot.scale = 0.86` + 몸통 반경 0.33→0.36 |
| 머리 최대폭 위치 | 위에서 0.35 | `HeadPivot.position.y = 0.50` |
| 목 잘록한 곳 | 위에서 0.48 | 머리를 올려 몸통과 겹침을 줄임 |
| 모자 세로 | 위에서 0~0.22 | 크라운 반경 0.235 |
| 귀 위치 | 머리 **옆이 아니라 위**, 중심이 머리 반경의 0.48배 바깥 | `EarPivot` y 0.275, x ±0.168 |
| 귀 모양 | 앞뒤로 눌린 원반 | scale (0.95, 1.05, 0.55) |

머리가 몸보다 컸던 것(1.06)이 눈사람으로 보이던 원인이다.

## 도안이 말해 준 것 하나 더

**몸에 털 결이 없다. 완전히 매끈한 클레이다.**
결을 내려고 구를 뿌려 놨었는데, 캐릭터가 화면에서 100px 인데 뭉치는 3~5px 이라
결이 아니라 혹으로 보였다. 크기를 키워도 줄여도 마찬가지였다. 지금은 없다.

| 파트너 털 | `#C0906C` | 리더보다 한 톤 밝다 — 나란히 놓으면 구분된다 |

**도안 값을 그대로 쓰면 안 된다.** 도안은 스튜디오 조명 기준이라 게임 실내조명에서
하얗게 날아간다. 모자와 크림 배는 한 단계씩 내려서 넣었다.

## 도안에 없어서 뺀 것

- **볼터치(분홍 점 두 개)** — 붙이면 쿼카가 아니라 곰인형으로 보인다
- **몸통 털 뭉치** — 위 참고

## 도안에 있어서 넣은 것

- **눈썹** — 이게 없으면 표정이 안 생긴다. `set_emotion` 이 눈 크기만 바꾸던 이유
- **웃는 입** — 작은 구를 호를 따라 늘어놓아 만든다. 표정마다 호 방향만 바꾸면 된다
- **발** — 없으면 몸이 바닥에서 잘린 것처럼 보인다
- **크림 주둥이** — 코 둘레만. 넓게 잡으면 수염처럼 보인다

## 표정

`expressions.jpg` 의 여덟 개가 `set_emotion()` 이 가야 할 곳이다.
지금은 눈 크기만 바뀐다 — 귀와 입은 아직 안 움직인다.

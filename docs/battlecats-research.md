# 냥코대전쟁 조사 — 우리 게임에 가져올 것 (2026-10)

> 규칙만 참고한다. 이름·캐릭터·그림·대사는 하나도 가져오지 않는다 (PONOS 의 저작물). 우리 쿼카·꿈결 세계로 옮긴다.

## 1. 한 판의 구조 (가로 한 줄 싸움)
- 왼쪽 우리 성, 오른쪽 적 성. 사이의 **한 줄 길** 위에서 양쪽 유닛이 걸어와 부딪친다. 적 성을 부수면 이기고, 우리 성이 무너지면 진다.
- **돈이 저절로 찬다.** 일꾼 고양이 레벨을 올리면 돈이 더 빨리 차고 지갑 한도도 커진다 — 판 안에서의 "투자냐 소환이냐" 선택이 핵심 긴장.
- **유닛 버튼 = 비용 + 재사용 대기시간.** 돈이 되고 대기시간이 끝나면 눌러서 낸다. 싸고 빨리 다시 나오는 벽 유닛 ↔ 비싸고 느린 강한 유닛.
- **고양이 대포**: 충전되면 한 방, 앞의 적을 한꺼번에 밀어내거나 멈춘다. 보스를 밀어내는 데 쓰는 '비상 버튼'.
- **넉백**: 체력이 일정 비율 깎일 때마다 뒤로 튕겨 나간다 (유닛마다 넉백 횟수가 정해져 있다). 전선이 출렁이는 맛.
- **보스**: 나올 때 충격파로 우리 유닛을 전부 밀어낸다. 일부 판은 보스를 잡아야 적 성 보호막이 풀린다.

## 2. 유닛의 역할
| 역할 | 하는 일 | 원작의 예 (이름은 안 쓴다) |
|---|---|---|
| 벽(고기방패) | 싸고 빨리 나와 적을 막는다 | 기본·탱크형 |
| 근접 딜러 | 짧은 사거리로 세게 | 도끼형 |
| 범위 공격 | 붙은 적 여럿을 한 번에 | 다리 긴 형 |
| 빠른 돌격 | 빨리 달려가 적 원거리를 친다 | 소형 |
| 원거리 | 먼 데서 쏜다, 몸은 약하다 | 물고기·도마뱀형 |
| 거대 | 비싸고 느리지만 넉백을 안 받는다 | 거인형 |
| 방해 | 확률로 멈춤·느리게·약화·날려버림 | 희귀 유닛들 |

- 적에게 **속성**(빨강·떠다님·검정·금속·천사·외계·좀비 등)이 있고, 유닛마다 "○○ 속성에 강함/방해" 가 붙는다 → 판마다 편성을 바꿀 이유.
- **편성(라인업) 10칸**: 들고 나갈 유닛을 미리 고른다.
- **콤보**: 특정 유닛을 같이 편성하면 보너스 (시작 돈↑, 대포 충전↑, 공격력↑ 등).

## 3. 키우기 (중독 고리)
- **경험치(XP)로 레벨업** — 모든 판이 XP 를 준다. 판을 돌수록 강해진다.
- **진화**: 레벨 10 에 2단 모습, 나중에 3단(진짜 모습) — 생김새가 바뀌는 게 큰 보상.
- **보물**: 판을 깨면 확률로 '하급·보통·상급' 보물. 장 전체를 모으면 공격·체력 +50% 같은 영구 보너스 → "다 모을 때까지 한 번 더".
- **같은 장을 세 번** (1·2·3장 = 같은 지도, 적이 점점 세짐).
- **뽑기(캡슐)**: 무료 티켓·인게임 재화로 희귀 유닛을 뽑는다. 중복은 레벨 상한 돌파 재료.
- **에너지**: 판마다 에너지를 쓰고 시간이 지나면 찬다 — "조금 쉬었다 다시".
- **매일 접속 보상·이벤트 판·한정 유닛** — 돌아올 이유.

## 4. 왜 중독되나 (리뷰·커뮤니티가 꼽는 것)
1. **수집할 게 엄청 많다** (수백 마리) — 다음 유닛이 궁금하다.
2. **겉은 단순, 속은 깊다** — 버튼 몇 개지만 편성·타이밍·투자 판단이 있다.
3. **웃기고 귀엽다** — 이상한 모습의 고양이, 흑백 고양이와 화려한 배경의 대비.
4. **돈 안 써도 다 깬다** — 공정하다는 느낌.
5. **계속 새 게 나온다** — 이벤트·콜라보.

## 5. 우리 게임으로 옮기면 (안)
- **쿼카 군단**: 직업 쿼카 1마리 대신, 여러 쿼카 유닛(전사·마법사·궁수·도적 + 방패·꼬마·거대·날개 …)을 수집하고 10칸 편성.
- **꿈결의 성 ↔ 악몽 성**: 적은 지금 몬스터들 (물방울뭉·불똥콩·우두머리 …). 속성 = 구역 테마(물·불·바위·바람·…)로 연결.
- **판 안**: 꿈조각이 저절로 차고, 일꾼(꿈 우체부?) 레벨업, 소환 버튼 + 대기시간, **꿈 대포**, 넉백, 보스 충격파.
- **판 밖**: XP 레벨업 · 진화(모습 변화) · 구역 보물 · 뽑기(무료 티켓·재화만, 현금 결제 없음) · 콤보 · 매일 보상.
- **자는 동안 보상**은 유지 (꿈조각·XP).

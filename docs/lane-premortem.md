# 쿼카 군단 - 리뷰 분석 · 프리모템 · 가설 (2026-11-16)

디플래너 기획 조사 스킬(`dplanner-plan10`)의 4단계(VOC) · 7단계(가설) · 10단계(프리모템) 방법만 빌렸다.
돈 계산 단계(시장 규모 · 수익 · 재무)는 우리 게임에 결제가 없어 뺐다.

숫자 표시: `[S1]` 출처, `[가정]` 우리가 정한 값, `[추정]` 계산한 값(식을 같이 적음), `[확인 필요]` 사람이 정할 곳.

## 1. 리뷰에서 나온 불만과 칭찬 (같은 장르)

표본이 작다: 공개 리뷰·글 8곳 [S1~S8]. 앱 마켓 리뷰를 한꺼번에 받는 공식 경로가 없어 화면에 보이는 것만 읽었다.
레딧·다모앙·TV Tropes 는 자동 접속이 막혀(403) 검색 요약만 보고 숫자는 쓰지 않았다.

| 묶음 | 내용 (뜻만 요약) | 나온 곳 | 우리 게임은 |
|---|---|---|---|
| 불만: 에너지 | 판마다 에너지를 써서 키우려는 반복을 끊고 오래 기다리게 한다. 가장 많이 나온 불만 | S1 · S2 · S3 | **없다.** 지켜야 할 강점 |
| 불만: 벽과 반복 | 어느 순간 못 깨는 판이 나오고, 넘으려면 같은 판을 되풀이해 키워야 한다 | S1 · S4 · S5 | 1장은 봇 첫 도전 승률이 거의 100% [S9]. 2장 이후는 [확인 필요] |
| 불만: 뽑기 운 | 화려한 유닛은 운으로만 나오고 비싸서 판 후반에야 쓸 수 있다. 초반 뽑기 운이 나머지를 정한다 | S2 · S5 | 전설 4%, 60번이면 확정 [S9]. 기본 쿼카 8종은 판을 깨면 온다 |
| 불만: 저장이 날아감 | 앱을 지웠다 깔았더니 2년 키운 것이 사라졌다 | S6 | **같은 위험이 있다.** 저장이 폰 안 `user://lane.cfg` 하나뿐 |
| 불만: 손이 안 가는 싸움 | 자동으로 흘러가는 긴 판은 지친다. 너무 쉽고 자동이면 얕다 | S7 · S8 | 자동 소환 · 20배속이 있다 (없앨 예정) |
| 칭찬: 짧은 판 | 판 하나가 짧아 빠르게 느껴진다 | S2 | 1장 100판 1시간 [S9] → 판당 약 36초 [추정: 3600 ÷ 100] |
| 칭찬: 엉뚱함 | 이상하게 생긴 유닛과 적이 웃기다. 흑백 유닛과 화려한 배경의 대비가 잘 읽힌다 | S2 · S3 · S4 | 귀여움은 있다. **웃음 포인트는 약하다** [확인 필요] |
| 칭찬: 공정함 | 돈 안 써도 다 연다 | S4 | 현금 결제 없음. 지켜야 할 강점 |
| 칭찬: 겉은 단순 속은 깊다 | 버튼은 적지만 편성 · 타이밍이 다르다 | S3 · S4 | 손맛 보너스 · 꽃 과제가 이 몫 |

## 2. 프리모템 - "1년 뒤 쿼카 군단이 실패했다. 왜?"

| 위험 | 분류 | 급함 | 대응 |
|---|---|---|---|
| 앱을 지우거나 폰을 바꾸면 모은 친구가 다 사라져 화가 나서 떠난다 | **진짜 위험** | 높음 | 저장 코드 내보내기 · 불러오기 (서버 없이 글자 한 줄). 개인정보를 받지 않는다 |
| 자동 소환을 없앴더니 판이 손이 많이 가거나, 남겨 두면 게임이 혼자 논다 | **진짜 위험** | 중간 | 자동을 걷기 전에 손으로만 1장 10판을 해 보는 시험 (가설 H1) |
| 1장이 너무 쉬워 긴장이 없고, 2장에서 갑자기 벽을 만난다 | **진짜 위험** | 중간 | SimLane 으로 2장 판별 승률 곡선을 본다. 벽은 꽃 셋째 송이로만 둔다 |
| 수집 대상이 24종뿐이라 [S9] 두세 주면 다 모아 할 게 없다 | **말 안 하던 걱정** | 중간 | 3장 · 끝없는 길 · 진화를 언제 넣을지 순서를 정한다 [확인 필요] |
| 귀엽기만 하고 웃기지 않아 남에게 보여 줄 장면이 없다 | **말 안 하던 걱정** | 낮음 | 벌레 · 쿼카 반응에 엉뚱한 장면 몇 개 (진화 모습, 우두머리 등장) |
| 에너지가 없으면 하루에 다 깨 버린다 | 부풀려진 걱정 | 낮음 | 에너지는 넣지 않는다. 대신 매일 고리(임무 · 달력 · 도전)가 이미 있다 |
| 뽑기 운이 나쁘면 못 깬다 | 부풀려진 걱정 | 낮음 | 기본 쿼카만으로 1장을 깬다 [S9]. 60번 확정이 있다 |

## 3. 검증할 가설

| # | 가설 | 범주 | 확신 | 검증 방법 | 성공 기준 |
|---|---|---|---|---|---|
| H1 | 자동 없이 손으로만 해도 1장이 재미있다 | 재미 | 중간 | 사용자 + 지인 2~3명이 자동을 끄고 10판 | 10판을 다 하고 "더 하고 싶다" [가정] |
| H2 | 1장 1시간은 지루하지도 벅차지도 않다 | 난이도 | 중간 | 같은 시험에서 진 판 수와 걸린 시간 | 진 판 1~3, 판당 1분 안 [가정] |
| H3 | 꽃 · 임무 · 달력이 다음 날 다시 켜게 한다 | 고리 | 낮음 | 지인에게 일주일 두고 켠 날 수를 묻는다 (분석 도구는 넣지 않는다) | 7일 중 4일 이상 [가정] |
| H4 | 친구 24종이면 1장 · 2장 동안 수집 욕심이 이어진다 | 수집 | 낮음 | 2장 끝날 때 모은 수 (SimLane 출력에 더하기) | 2장 끝에 20종 안팎 [가정] |
| H5 | 저장이 날아가도 처음부터 다시 할 만하다 | 신뢰 | **틀렸다고 본다** | S6 같은 리뷰 | 저장 코드로 막는다 |

## 4. 다음 할 일 (추천 순서)

1. **저장 코드 내보내기 · 불러오기** - 진짜 위험 가운데 우리가 바로 막을 수 있는 것. 설정 창에 두 단추.
2. **손으로만 10판 시험 (H1 · H2)** - 사람이 한다. 결과로 자동 소환을 걷을지 정한다.
3. **2장 난이도 곡선** - SimLane 으로 2장 판별 승률을 뽑아 벽이 있는지 본다.
4. 수집 · 웃음 걱정은 3장 기획 때 다시 본다.

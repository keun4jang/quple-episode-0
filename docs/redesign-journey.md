# 쿼플 전체 재구상 — 여행하는 쿼카

> 상태: **전체 구상 (구현 전)**.
> 앞선 기획 넷(`redesign-simple` / `redesign-idle` / `redesign-quokka` /
> `redesign-kids` / `redesign-magic-english`)을 **모두 대체한다.**

## 0. 한 문장

> **쿼카 한 마리가 혼자 여행을 떠나, 여행지에서 만난 인연들과 그곳의 하루를 보낸다.**

스타듀밸리의 구조를 쓰되, **정착이 아니라 이동**이다.
그 하나가 이 게임의 모든 차이를 만든다.

## 1. 다섯 번을 살아남은 것

방향을 다섯 번 바꿨다. 그때마다 남은 것이 셋 있다.

**쿼카 · 여행 · 픽셀.**

나머지(방치형, 감정 도감, 영어 마법, 횡스크롤)는 다 붙였다 뗐다. 이번 구상은
살아남은 셋만 뼈대로 쓰고, 그 위에 스타듀밸리의 **검증된 구조**를 얹는다.

### 버리는 것

| | 줄 수 |
|---|---|
| 마법영자문 전체 (`scripts/word/`) | ~1,400 |
| 횡스크롤 0편 (`scripts/side/`) | 2,580 |
| 기념품 3D 방·통계·바람편지·엽서 | ~1,300 |
| 여행 허브 3단계 화면 (`travel_hub.gd`) | 1,228 |

### 살리는 것

| | 왜 |
|---|---|
| `save_manager.gd` (242줄) | 3단계 안전 저장 + 앱 전환 자동 저장. 그대로 쓴다 |
| `auto_update.gd` (342줄) | OTA 갱신. 그대로 |
| `audio_manager.gd` (1,128줄) | 그대로 |
| `settings_ui.gd` | 난이도 줄만 빼면 그대로 |
| **여행지 242곳 데이터** | 이름·한 줄 소개·소요시간. **이번엔 진짜로 쓴다** |
| 쿼카 3D 렌더 에셋 | 픽셀 변환의 원본 |
| `tools/pixel/pixelize.py` | 화풍 파이프라인 |

## 2. 스타듀밸리에서 가져올 것 / 안 가져올 것

### 가져온다
- **탑다운 타일 세계** — 걸어 다니고, 화면이 따라오고, 물건이 놓여 있다
- **하루 사이클** — 아침에 시작해 밤에 잔다. 하루가 단위다
- **주민과 호감도** — 말을 걸고, 선물하고, 사연을 알게 된다
- **계절** — 풍경과 할 수 있는 일이 바뀐다
- **내 공간** — 돌아와 쉬고, 모은 것을 놓는 곳

### 안 가져온다

| 스타듀 | 우리가 안 쓰는 이유 |
|---|---|
| 농사·광질·전투 | 여행자는 땅을 갈지 않는다. **걷고 보고 만난다** |
| 체력이 떨어져 기절 | 벌이 있으면 힐링이 아니다 |
| 돈 벌기 압박 | 수익 목표를 두는 순간 여행이 노동이 된다 |
| 결혼·자녀 | 우리 감정선은 다르다 (5절) |
| 시간에 쫓기는 이벤트 | "그날 그 시간에 못 가서 놓침"은 스트레스다 |

**핵심 차이 한 줄**: 스타듀는 *머무는* 게임이고, 우리는 *지나가는* 게임이다.
그래서 감정의 축이 **"떠남과 재회"** 가 된다.

## 3. 코어 루프

```
   ① 여행지에 도착한다
        ↓
   ② 하루를 보낸다 — 걷고, 만나고, 사진 찍고
        ↓
   ③ 밤에 숙소로 돌아와 일기를 쓴다
        ↓
   ④ 며칠 머물다 → 다음 여행지로 떠난다
        ↓
   ⑤ 떠난 곳의 인연이 편지를 보내온다 / 다른 곳에서 다시 만난다
        └──────────→ ①
```

| 단위 | 길이 | 무엇이 남나 |
|---|---|---|
| **하루** | 실플레이 5~10분 | 사진 1~2장, 인연 한 칸 |
| **한 여행지** | 3~7일 | 그곳의 이야기가 닫힌다 |
| **한 계절** | 여행지 3~4곳 | 재회가 시작된다 |

## 4. 세계 구조 — 여행지가 마을을 대신한다

스타듀는 펠리컨 마을 하나를 깊게 판다. 우리는 **얕지만 여러 곳**을 간다.
그게 여행이니까. 대신 얕아서 생기는 허전함을 **재회**로 메운다 (5절).

### 여행지 한 곳의 크기

```
   숙소  ─  마을길  ─  시장       한 곳 = 화면 6~9개 분량
     │        │        │          (스타듀 마을의 1/3쯤)
   바닷가  ─  언덕  ─  전망대
```

- 걸어서 끝에서 끝까지 **2분** — 길을 잃지 않을 크기
- 지도는 안 만든다. 길이 헷갈리면 그 자체로 잘못 만든 것이다
- **여행지 242곳 데이터**를 여기에 쓴다. 다만 242곳을 다 만들지는 못한다 —
  손으로 만드는 곳 10~15곳 + 나머지는 **틀 조합**으로 (12절)

### 여행지의 틀 6종

같은 틀에 색·소품·주민만 갈아 끼운다. 이게 없으면 여행지 하나에 일주일 걸린다.

| 틀 | 분위기 | 예 |
|---|---|---|
| 🌊 바닷가 마을 | 짜고 느리다 | 부산, 니스 |
| ⛰ 산골 | 조용하고 춥다 | 강원, 스위스 |
| 🏙 도시 | 빠르고 낯설다 | 서울, 도쿄 |
| 🏜 사막 | 넓고 비어 있다 | 카이로 |
| 🌴 섬 | 작고 다 안다 | 제주, 발리 |
| ❄ 설원 | 하얗고 고요하다 | 삿포로 |

## 5. 인연 — 이 게임의 심장

여기가 스타듀와 가장 다른 곳이고, **이 게임을 만드는 이유**다.

### 두 종류의 사람

| | 붙박이 | 여행자 |
|---|---|---|
| 누구 | 그 마을에 사는 이 | 나처럼 지나가는 이 |
| 다시 만나려면 | **그 여행지에 다시 오면** | **어디서든 우연히** |
| 감정 | 돌아갈 곳이 생긴다 | 놀라움 |

**여행자 NPC가 이 게임만의 것이다.** 부산에서 만난 너구리를 파리에서 다시 만난다.
"어? 너 여기 웬일이야?" — 이 한 순간을 위해 나머지가 다 있다.

### 마음 다섯 칸

숫자도 하트 개수도 안 보여 준다. **말투가 바뀌는 것**으로 안다.

| 칸 | 무엇이 바뀌나 |
|---|---|
| 1 | 존댓말. 날씨 얘기 |
| 2 | 이름을 불러 준다 |
| 3 | 자기 얘기를 조금 한다 |
| 4 | 같이 어딘가에 가자고 한다 |
| 5 | **엽서를 준다** — 떠난 뒤에도 편지가 온다 |

### 어떻게 친해지나 — 대화 말고

말 걸기 반복으로 오르는 건 지루하다. **같이 뭔가를 해야** 오른다.

- 🚶 같이 걷기 (그 사람이 좋아하는 곳까지)
- 📷 사진 찍어 주기
- 🍜 나눠 먹기
- 🎁 그곳에서 주운 것 건네기
- 🌇 같이 앉아 해 지는 것 보기 (아무것도 안 하는 시간)

### 파트너는 없다 — 끝까지 혼자다

> **결정됨.** CLAUDE.md 의 캐릭터 규칙을 "쿼카 여행자 — 혼자 여행한다"로 바꿨다.
> 쿼카 커플 / 리더 / 파트너는 더 이상 쓰지 않는다.

동행이 생기지 않는다. 이건 제약이 아니라 **이 게임이 하려는 말**이다.

- 인연들은 **끝까지 지나가는 사람**으로 남는다. 붙잡히지 않는다
- 그래서 재회가 값지다. 언제 또 볼지 모르니까
- 마음 다섯 칸의 끝은 함께 떠나는 게 아니라 **엽서를 받는 것**이다

혼자라는 게 쓸쓸하기만 하면 안 되므로, 두 가지로 받친다.

1. **혼자여서 좋은 것들을 보여 준다** — 아무 데나 앉기, 계획 없이 방향 바꾸기,
   말없이 오래 있기. 동행이 있으면 못 하는 것들
2. **편지가 쌓인다** — 지나온 곳에서 편지가 온다. 지금 옆에 없어도 **연결은 남는다**

엔딩도 여기서 나온다. 여행을 마칠 때, **모아 둔 엽서를 한 장씩 넘겨 본다.**
혼자 다녔는데 손에 남은 게 이만큼이라는 것.

## 6. 하루와 시간

- **아침 6시 시작 → 밤 12시.** 실시간 1초 = 게임 10초 정도 (하루 ≈ 8분)
- **체력 없음. 기절 없음.** 밤을 새워도 벌이 없고, 그냥 밤 풍경을 본다
- 자면 다음 날. **자야만 저장되는 게 아니다** — 자동 저장은 늘 돈다
- 주민은 시간대별로 다른 데 있다. 아침 시장, 낮 언덕, 밤 바닷가

**실제 시각은 안 쓴다.** 오프라인 진행은 이번엔 버린다 — 앉아서 하는 게임이 됐으니까.

## 7. 조작 — 모바일 우선

| 손가락 | 하는 일 |
|---|---|
| **한 손가락 끌기** | 이동 (누른 자리에 가상 스틱) |
| **탭** | 앞의 것과 상호작용 / 대화 넘기기 |
| **두 손가락 오므리기·벌리기** | **화면 확대·축소** |
| 두 손가락 끌기 | 잠깐 둘러보기 (놓으면 캐릭터로 복귀) |

### 확대·축소 규칙 (요청하신 것)

픽셀 아트에서 줌은 조심해야 한다. 아무 배율이나 허용하면 **픽셀이 어긋나 지글거린다.**

- 배율은 **정수만** — 2× / 3× / 4×. 기본 3×
  > 처음엔 0.5 단위로 적었는데, 붙여 보니 2.5배에서 원본 한 픽셀이 화면
  > 2.5픽셀이 되어 어떤 픽셀은 두 칸, 어떤 픽셀은 세 칸을 차지했다.
  > 격자가 울퉁불퉁해지고 걸으면 지글거린다. **정수 세 단계면 충분하다** —
  > 넓게 보기 · 기본 · 얼굴 보기.
- 세로로 들면 화면이 좁으니 한 단계 넓게 보여 준다
- 오므리는 동안엔 부드럽게 따라오고, **손을 떼면 가까운 눈금으로 붙는다**
- 확대 중심은 **두 손가락 사이**. 화면 중앙이 아니다 — 보려던 걸 놓친다
- 세로/가로 둘 다 되게. 세로일 때 최소 배율을 한 칸 낮춘다

## 8. 픽셀 규격

| | 값 |
|---|---|
| 타일 | **16 × 16 px** (스타듀와 같다) |
| 캐릭터 | 16 × 24 px (쿼카는 땅딸막하다) |
| 내부 해상도 | **480 × 270** (16:9, 정수 배율로 4K까지 깨끗) |
| 팔레트 | 기존 에셋에서 뽑은 32색 (`tools/pixel/pixelize.py`) |
| 정렬 | Y-sort. 아래 있는 것이 앞에 |

쿼카는 기존 3D 렌더를 `pixelize.py` 로 내려 원본으로 쓴다. 방향 4종 × 걷기 4프레임.

## 10. 무엇이 쌓이나

돈도 레벨도 없다. 대신 셋이 쌓인다.

| | 무엇 |
|---|---|
| 📷 **사진첩** | 직접 찍은 장면. 언제 어디서 누구와 |
| 📖 **일기** | 하루 끝에 한 줄. 그날 한 일에서 자동으로 만들어진다 |
| ✉ **엽서** | 마음 다섯 칸을 채운 인연에게서 온다. 떠난 뒤에도 |

**돈은 있다. 다만 목표가 아니다.** 차비와 밥값 정도. 벌이 수단은 사진 팔기 한 가지.

| | |

| 계절 | 타일셋 교체 + `mood_palette.gd` 재사용 |

## 12. 정직하게 — 이게 제일 중요하다

### (1) 스타듀밸리는 1인 개발 4년 반이다

이 구상을 다 만들면 **몇 년짜리**다. 그대로 가면 못 끝낸다.
→ 13절의 최소 버전으로 **여행지 한 곳만** 먼저 만든다. 거기서 재밌으면 늘린다.

### (2) 타일 그림이 없다

지금 `assets/tiles/` 와 `assets/sprites/` 가 **비어 있다.** 탑다운 게임은 타일이
전부인데 하나도 없다. 그리고 CLAUDE.md 규칙상 **유료 에셋은 못 산다.**

세 가지 길이 있고, 전부 문제가 있다.

| | 장점 | 문제 |
|---|---|---|
| 직접 그린다 | 우리 것이 된다 | 여행지 한 곳에 타일 100장 넘게 필요 |
| **무료 CC0 타일셋** | 당장 시작 가능 | 화풍이 쿼카와 안 맞을 수 있다. 출처·라이선스 확인 필수 |
| 코드로 생성 | 무료·빠름 | 스타듀 같은 밀도가 안 나온다 |

→ 제안: **CC0 타일셋으로 뼈대를 세우고, 눈에 띄는 것만 직접 고쳐 쓴다.**
어차피 최소 버전은 "재밌는지" 보는 게 목적이지 출시본이 아니다.

### (3) 여행지 242곳은 못 만든다

손으로 만들면 곳당 최소 이틀이다. 242곳이면 1년 반이다.
→ 6종 틀 + 조합으로 가되, **정직하게 20~30곳을 목표로 한다.** 데이터는 남겨 둔다.

### (4) 대상 연령 — **정해짐: 전 연령 힐링**

스타듀밸리처럼 어른도 즐기는 힐링 게임으로 간다. 대사와 사연을 깊게 쓸 수 있다.
다만 **광고·인앱결제·개인정보 수집 없음**은 그대로 유지한다
(`redesign-kids.md` 7절에서 정한 것 중 이것만 살린다).

### (5) 캐릭터 — **정해짐: 끝까지 혼자**

CLAUDE.md 의 "쿼카 커플(리더/파트너)"를 "쿼카 여행자"로 바꿨다.
동행은 생기지 않고, 인연들은 지나가는 사람으로 남는다 (5절).

### (6) 오프라인 진행을 버린다

이 게임의 가장 오래된 자산(`앱을 꺼도 여행이 진행된다`)이 사라진다.
앉아서 조작하는 게임이 됐으니 맞는 결정이지만, **버리는 것임을 알고 버려야 한다.**

## 13. 최소 버전 — 여기까지만 먼저

**여행지 한 곳, 사흘, 주민 셋.** 이것만 만들고 판단한다.

1. **걷기** — 탑다운 이동, 카메라 따라오기, **핀치 줌**
2. **여행지 한 곳** — 화면 6개 분량 (숙소·마을길·바닷가)
3. **하루 사이클** — 아침 6시 → 밤 12시 → 자기
4. **주민 셋** — 붙박이 둘, 여행자 하나. 마음 세 칸까지
5. **사진 찍기** — 찍은 자리가 사진첩에 남는다
6. **일기 한 줄** — 하루 끝에 자동으로
7. **떠나기** — 다음 여행지로. **여기서 여행자 하나를 다시 만난다** ← 이게 증명해야 할 것

7번이 이 게임의 전부다. **재회가 뭉클하지 않으면 나머지는 안 만들어도 된다.**

1~2번만 해도 **핀치 줌으로 픽셀 마을을 돌아다니는 화면**이 나온다.
거기서 화풍과 손맛을 먼저 보는 게 순서다.

# 쿼카 군단 — 냥코대전쟁식 세로 한 줄 싸움 (0.1.221~)

> 이름 (2026-11-01): 소재는 꿈이 아니라 **행복**이다. 꿈빛 → **웃음**(판 안의 힘), 꿈조각 → **행복 조각**, 꿈별 → **행운별**, 꿈 캡슐 → **행복 캡슐**, 꿈 대포 → **바주카포**.

> 결정 (2026-10): 직접 소환 + 자동 소환 버튼 · 세로 화면, 아래(쿼카 성)→위(벌레 둥지) 진군 · 쿼카 군단 수집 ·
> 기존 키우기 요소는 냥코식으로 갈아끼운다 · **악당은 벌레, 최종 보스는 바퀴벌레 대왕**.
> 조사: `docs/battlecats-research.md`. 규칙만 빌린다 - 이름·그림은 우리 것.

## 한 판
- 길 하나 (`LaneData.LEN` = 3000). 0 = 쿼카 성(아래), 끝 = 벌레 둥지(위). 원근: 먼 쪽이 작고 위로 눌린다 (`LaneField`).
- **웃음**이 저절로 찬다. **수입** 버튼(일꾼)으로 초당 양과 한도를 올린다 — 투자냐 소환이냐.
- 쿼카 버튼 = 웃음 + 대기시간. 사거리 안에 적이 오면 멈춰서 친다. 범위 공격은 붙은 적 전부 + 둥지.
- **넉백**: 체력이 넉백 횟수로 나뉘어 깎일 때마다 튕겨 나간다. 거대 쿼카는 안 밀린다.
- **바주카포** (옛 꿈 대포): 40초 충전, 포탄이 둥지까지 날아가며 길 위 벌레 전부 피해, 성 앞 900 안은 넉백, 둥지 체력 3% (`CANNON_NEST`). 피해 240 (사용자 요청으로 120 에서 두 배). 30초·길 전체 넉백·둥지 6% 는 1장이 7시간에서 4.5시간으로 쉬워져 줄였다 (SimLane 두 씨앗 평균 6.6 → 6.1시간). 강화(Lv10)·우리 성 강화(Lv10, 체력 +15%씩)는 행복 조각으로 - 동물 탭 맨 위.
- **우두머리**: 나올 때 충격파로 쿼카를 전부 밀어낸다. 우두머리 판은 졸개를 덜 보낸다.
- 둥지 체력이 절반 아래로 떨어지면 졸개가 몰려온다.
- **자동 소환**(벽이 모자라면 벽부터 → 수입 → 가장 센 것 → 몰리면 대포)과 **빨리 감기**(1배 → 3배 → 20배, `LaneData.SPEEDS`). 20배는 시험하는 동안만 둔다 (0.1.275).
- **1장은 1시간 안팎** (0.1.277, 사용자 요청 - 오래 걸리면 안 된다): 판 빠르기 `PACE` 3 (싸움 안의 모든 시간이 3배로 흐른다 - 1배속 버튼이 곧 이 빠르기),
  1장 둥지 체력 `NEST_MULT` 0.6, 1장 벌레 세기 `CH1_BUG` 0.5. SimLane 씨앗 7·11: 1장 1.0시간(예전 4.1), 2장까지 2.9시간, 진 판 0~7.
  봇 기준 첫 도전 승률이 거의 100% 라 1장은 쉬운 편이다 - 손맛·꽃이 재미를 맡는다.
- **후퇴는 없다** (0.1.276): 판은 이기거나 성이 무너질 때까지 끝까지 싸운다. 진 판 제목은 "졌어요…".
- **결과 창은 짧게** (0.1.276): 꽃 셋 → 못 받은 꽃의 조건 한 줄 → 받은 것 한 줄(행복 조각 · 행운별 합계, 꽃·꽃다발 몫 포함) → 보물·새 친구 같은 드문 일 → 끝낸 임무 수 한 줄.

## 판 밖
- 10 구역 × 10 판 = 100판. 구역마다 벌레 셋~넷 + 우두머리. 첫 벌레는 끝없이 오는 졸개, 뒤의 것은 구역 뒤 판에서 섞인다.
- 쿼카 8종 (꼬마·방패·창·망치·날쌘·새총·마법·거대) — 판을 깨면 합류. 레벨은 행복 조각으로 (+20%/레벨, 최대 20).
- 편성 10칸. 보상: 행복 조각(처음 깨면 두 배) · 행운별(처음 깨면, 뽑기용 - 3단계).
- 자는 동안 행복 조각 (최대 8시간). 저장은 `user://lane.cfg` (지금 게임과 따로).

## 시뮬레이션 (`tools/sim/SimLane.tscn`, 봇 = 자동 소환 + 낮은 레벨부터 고르게)
- 기본 쿼카만으로 100판까지 7.3~9.9시간 (씨앗 3개). 보통 판 1~2분, 우두머리 판 2~4분.

  그대로면 몰려서 진다 / 봇이 수입을 안 올리면 늘 웃음이 모자라다.

## 2단계 — 동물 친구 16종 + 행복 캡슐 뽑기 (0.1.223)
- 냥코의 중독 고리 = **"다음엔 누가 나올까"**. 쿼카 8종(판을 깨면 합류) 위에 동물 친구 16종을 뽑기로 만난다.
  - 희귀 8: 병아리·고슴도치·다람쥐·개구리·토끼·오리·두더지·양
  - 특급 5: 거북이·펭귄·부엉이·판다·수달
  - 전설 3: 호랑이·북극곰·독수리
- 특성 (`LaneData` 의 `strong`·`massive`·`crit`·`kb_hit`·`slow`): 강함 = 1.5배로 때리고 반만 맞음, 굉장히 강함 = 2.5배,
  치명타 2배, 밀어내기 확률, 느리게(trait "all" = 모두). 계산은 `LaneBattle._strike()` 한 곳.
- 뽑기: 1번 ★100 / 10번 ★900(마지막 특급 이상 확정), 희귀 72·특급 24·전설 4%, 60번 천장, 첫 뽑기 특급 이상,
  아직 없는 친구 1.5배 가중. 중복 = 레벨 +1 (최고면 행복 조각). 진짜 돈 없음.
- 행운별: 첫 클리어 6+2×구역 (우두머리 20+5×구역 + 티켓 1장), 다시 깨면 1, 선물 달력(티켓 1 + ★30, 7·21칸 티켓 3 + ★100, 14·28칸 특급 캡슐 + ★100).
- **강한 효과는 몰아서 쓴다**: 캡슐 여는 순간(등급만큼 흔들리며 색이 바뀌고, 전설은 빛 줄기·금가루·"전설!"),
  전설 출전(빛기둥·배너), 치명타(금빛 베기·히트스톱), 굉장히 강함(분홍 "굉장!"). 평소 타격은 작게 둬야 이 순간이 산다.
- 캡슐은 달걀 모양 + 별 스티커 + 톱니 이음매 (남의 유명한 공 모양을 피했다).
- 시뮬레이션 (`SIM_GACHA=1`, 하루 1.5시간 놀아 매일 선물, 센 편성 + 편성만 레벨업):
  뽑기 30번 안팎, 100판 5.6~7.6시간. 뽑기 없이는 12~16시간 → 뽑기가 확실히 도움이 된다.
  동물이 처음엔 너무 세서(0번 지고 3시간) 체력·공격 −25%, 특급 −10%, 전설 −20%·비용 +20%, 벌레 배율 0.03→0.036,
  바퀴벌레 대왕 공격 380→290·걸음 110→80 으로 맞췄다.
- 다음: 구역 보물 · 장신구 · 콤보 · 기존 저장 옮기기 · 기존 게임과 교체. 친구는 이벤트처럼 계속 늘린다.

## 3단계 — 보물 · 장신구 · 콤보 · 옛 저장 선물 · 기본 게임 교체 (0.1.224)
- **보물** (`LaneData.TREASURES`, 구역마다 3개 × 하급·보통·상급): 처음 깨면 60%, 다시 깨면 30% 로 그 구역 보물이 나온다.
  더 좋은 등급만 남는다. 효과는 공격·체력 %, 수입 %, 대포 충전 %, 행복 조각 %, 시작 웃음. 지도 카드에 등급 색 테두리로 보인다.
- **장신구** (`LaneData.ACCESSORIES` 10개): 구역 우두머리를 처음 잡으면 하나씩. 유닛 하나에 하나 단다(다른 유닛에 달면 옮겨 감).
  걸음·공격·체력·치명타·느리게·공격 간격·다시 내기·비용·받는 피해. 행복 조각으로 Lv5 까지 강화 → 행복 조각을 쓸 곳이 하나 더.
- **콤보** (`LaneData.COMBOS` 10개): 정해진 친구들을 같이 편성하면 판 전체 보너스. 편성 탭 아래에 보인다.
- 계산: 판 전체 보너스 = `LaneState.bonuses()` (보물 + 콤보) → `LaneBattle.start()`. 장신구는 `unit_stats()` 안에서 그 유닛만.
- **옛 꿈결 키우기 저장** 은 지우지 않고, 쿼카 군단 첫 실행 때 한 번만 선물로 바꾼다 (`migrate_from_idle`: 가장 멀리 간 판 ×6 행운별,
  티켓 2+판/15, 레벨×400 행복 조각). 처음부터 하기를 눌러도 다시 받지 않는다.
- **메뉴의 시작하기 = 쿼카 군단.** 옛 게임 파일은 남겨 뒀지만 메뉴에서는 뺐다.
- 시뮬레이션 (보물·장신구·콤보 포함, 봇 편성 두 방식 × 씨앗 3): 6번 모두 100판 완주, 3.3~9.8시간 (뽑기 운에 따라).
  뽑기 없이 5.9시간. 벌레 배율을 0.055 로 올려 보니 중반(6~7구역)이 벽이 돼서 0.036 으로 두고 보물·장신구 효과를 낮췄다.
  지네 대왕 공격 300→230 · 간격 1.4→1.6.

## 4단계 — 라벤더 + 노랑 색, 아슬아슬한 난이도 (0.1.225)
- **색** (0.1.234 에서 다시): 노랑을 빼고 **라벤더(#BF94E4) = 키 컬러, 벚꽃 분홍(#F7A8C4) = 포인트**. `IdleUi.GOLD` 는 이름만 옛것이고 지금은 분홍. 홈 배경은 벚꽃 풍경(구역 8). 밝은 라벤더 판·흰 카드·라벤더 버튼·노란 주 버튼,
  글씨는 진한 자두색. `IdleUi` 상수 한 곳에서 바꿨다 (`CREAM` 은 이름만 옛것, 지금은 본문 진한 글씨).
  밝은 글씨(노랑·초록)는 `label()` 이 자동으로 자두색 테두리를 두른다.
- **난이도 원칙: 어렵지만 깰 수 있게, 이기더라도 아슬아슬하게.** 시뮬레이션으로 구역마다 *첫 도전 승률* 과 *이길 때 남은 성 체력*
  을 잰다 (`SIM_TENSION=1`). 전에는 1~6구역이 100% / 성 100% (성이 한 번도 안 맞음) - 긴장이 없었다.
  - **벌레 떼** (`WAVE_*`): 주기적으로 한 덩어리가 줄지어 와서 전선을 민다. 3초 전에 "벌레 떼가 몰려와요!".
  - **위기 역전** (`CRISIS_AT` 0.4): 성이 40% 아래로 처음 떨어지면 대포가 바로 차고 웃음이 들어온다 - 버티다 뒤집는 순간.
  - **다시 도전 응원** (`CHEER_*`): 같은 판에서 질 때마다 +10% (최대 +30%), 이기면 사라진다 - 어려워도 결국 깬다.
  - **구역 세기** (`ZONES[].pow`, `zone_pow`): 벌레 조합마다 어려움이 달라 구역별로 맞췄다. 첫 구역 앞 판은 배우는 판이라 살살.
  - 첫 뽑기 특급 확정은 뺐다 (특급 하나가 초반 두 구역을 혼자 쓸어서 긴장이 없었다). 10번 뽑기 특급 확정은 그대로.
  - 성이 반 아래면 화면 가장자리가 붉게 맥박친다.
- 목표: 첫 도전 승률 60~85%, 이길 때 남은 성 30~80%. 1구역(배우는 판)과 마지막 구역(가장 어려움)은 예외.
- 0.1.226 점검: 바로 후퇴를 눌러 응원(+30%)을 공짜로 쌓을 수 있던 허점을 막았다 (성이 무너졌거나 60초 넘게 싸운 판만).
  매일 선물을 UTC 가 아니라 기기 시간대 자정에 바꾼다 (한국은 아침 9시에 바뀌고 있었다), 켜 둔 채 자정이 지나도 홈에서 받는다.
  참나무 숲(4구역) 졸개·떼를 무당벌레(껍질) → 꿀벌로 바꿨다 - 껍질에 강한 친구가 있으면 100%, 없으면 10% 로 갈렸다.
  시뮬레이션 3번 모두 100판 완주 6.0~9.2시간, 구역 첫 도전 승률 대부분 60~100%, 이길 때 성 30~90%.

## 5단계 — 그림 컨셉 하나로: 전부 도트 (0.1.228)
- 캐릭터는 도트인데 배경·길·효과가 매끈한 그림이라 따로 놀았다 (사용자 의견).
- 배경(`IdleBackdrop`)·길·성·둥지(`LaneField`)를 `SubViewportContainer`(stretch_shrink 3) 안에서 그린다 -
  1/3 크기로 그려 3배로 키우니 **배경 픽셀 = 캐릭터 픽셀(3점)**. 노드들은 화면 좌표 그대로 그리고, 줄이는 건
  뷰포트의 `canvas_transform` 이 한다 (`LaneGame._pixel_layer`).
- 캐릭터는 원근 때문에 크기가 0.62~1배로 변해 픽셀 크기가 제각각이었다 → **크기 하나(3점)**, 위치도 3점 칸에 맞춘다.
- 머리 위 체력 띠도 3점 칸 도트로. 효과(`IdleFx`·`IdleVfx`)는 2배 도트 - 3배면 데미지 숫자가 안 읽힌다.
- 홈 화면 뒤 풍경도 같은 도트 판. 창·버튼(UI)은 읽기 좋게 매끈한 채로 둔다 (도트 게임들도 보통 UI 는 깔끔하게 간다).

## 공격 동작 (0.1.229)
- 공격 4칸을 **동작이 보이게** 다시 그렸다 (`make-quokka-units.py` 의 `ATTACK_POSE`·`strike_fx`, 동물·벌레 같은 방식):
  0 웅크려 당김 → 1 적 쪽(위)으로 크게 휘두름 + 반달 잔상 → 2 끝에서 반짝 → 3 돌아옴. 개구리는 혀를 뻗고, 새는 쪼고,

- **떼 막기**: 벌레 떼를 마지막 하나까지 길 가운데(`WAVE_HOLD_AT`) 너머에서 쓰러뜨리면 웃음 +150 (자동이 꺼져 있을 때).
- 결과 창 맨 아래에 '여럿 맞히기 N번 · 떼 막기 N번' (하나라도 있을 때).

## 판마다 꽃 세 송이 + 구역 꽃다발

이긴 판을 "한 번 더" 할 이유. 판마다 꽃 셋을 모은다 (`LaneState.flowers`, 판 → 비트 1·2·4).
한 판에 다 받아도, 여러 번 나눠 받아도 된다. 다시 도전 응원을 받은 판도 인정한다.

- 꽃 1 **이기기** · 꽃 2 **성 체력 60% 이상 남기고 이기기**(`FLOWER_HP`) · 꽃 3 **그 판의 손맛 과제**(`LaneData.flower_task`).
  - 우두머리 판: 바주카포로 우두머리 마무리. 보통 판은 n%3 으로 -
    바주카 한 방에 3~6마리(구역이 뒤일수록 많이) / 웃음을 꽉 채운 채 둔 시간이 모두 10초 이하 / 벌레 떼를 한 번 막기.
  - **자동을 한 번이라도 켠 판은 꽃 3을 못 받는다** (`tally.auto_used`). 판 이름 아래에 과제가 늘 떠 있고,
    자동을 켜면 '자동으로 싸우면 셋째 꽃은 쉬어요' 로 바뀐다.
- 보상: 새로 받은 꽃 2·3 하나마다 행운별 2(1장)·3(2장) (`FLOWER_STAR`). 꽃 1은 첫 클리어 보상이 따로 있다.
  다 모으면 1장 400 + 2장 600 = 1000 (뽑기 10번어치) - 첫 클리어 행운별 합계 5850 에 견줘 크지 않다.
- **구역 꽃다발**: 구역(장마다 따로, 0~19) 10판의 꽃이 20이면 행운별 20, 30이면 뽑기 티켓 1장 (`BOUQUET`, 한 번씩).
- 지도 판 단추 아래에 꽃 셋, 구역 머리에 '꽃 N / 30'. 결과 창에서 새 꽃은 하나씩 피어난다.
- 옛 저장(꽃이 없던 때)은 깬 판마다 꽃 1만 핀 것으로 (보상 없음).

## 오늘의 임무 + 이번 주 도장판 (매일 · 매주)

날마다 들어올 이유 하나, 한 주를 이어 갈 이유 하나. 처음 안내를 마치고 세 판을 깬 뒤부터 홈 위 줄
(톱니 왼쪽, 상자 단추)에 열린다. 받을 것이 있으면 탭과 같은 분홍 점. 날짜는 폰의 로컬 자정(매일 선물과 같다).

- **임무 셋** (`LaneData.MISSIONS`): 쉬움·보통·손맛에서 하나씩, 행운별 10·15·20. 씨앗이 `today * 7919` 라
  같은 날은 몇 번 켜도 같은 임무다. 열림 조건이 있는 것(우두머리는 10판, 다섯 종은 편성 5)은 그 전엔 안 나온다.
- **세기** (`LaneState.add_tally`): 판이 끝날 때 이기든 지든 후퇴하든 그때까지 한 만큼 센다.
  판 기록(`tally`)을 읽으니 자동 소환·자동 바주카는 저절로 빠진다. '성 70% 지키고 이기기'는 자동을 켠 판이면 안 센다.
  레벨 올리기는 `level_up` 이 센다. 결과 창 아래에 이번 판으로 오른 임무가 한 줄씩(최대 3).
- **받기**: 다 해도 저절로 들어오지 않는다 - '받기'를 눌러 받는다. 셋 다 받으면 그날 도장 하나 (하루 하나까지).
  못 한 임무는 벌 없이 자정에 사라진다. 하루 한 번 공짜로 임무 하나를 같은 등급의 다른 것으로 바꿀 수 있다(진행 0).
- **이번 주 도장판**: 7칸, 월요일 0시에 새로 (`week = (today + 3) / 7` - 1970-01-01 이 목요일).
  3칸 뽑기 티켓 1 · 5칸 티켓 1 + 행운별 50 · 7칸 특급 이상 행복 캡슐 한 번(전설 천장에 센다, 뽑기 연출 그대로).
  칸 보상도 단추로 받는다. 한 주를 다 채우면 임무 315 + 50 행운별, 티켓 2, 특급 캡슐 - 뽑기 6번쯤.
- 남은 날짜·시간은 보여 주지 않는다 (압박 X). '월요일에 새 도장판' 한 줄만.

## 선물 달력 (매일 출석 · 끊겨도 이어지는 28칸)

옛 '매일 선물'(이어 받은 날 수, 하루 빠지면 처음부터)을 바꿨다. 빠진 날 때문에 처음으로 돌아가면
다시 오기 싫어진다 - 벌 대신 '오면 한 칸'.

- 오늘 처음 들어오면 한 칸 (`LaneState.claim_daily` → `cal_day`, 1~28, 28 다음은 다시 1).
  **빠진 날이 있어도 칸은 그대로** - 되돌아가지 않는다. 날짜는 폰의 로컬 자정.
- 칸 보상 (`LaneData.calendar_gift`): 보통 날 티켓 1 + 행운별 30 · 7·21칸 티켓 3 + 행운별 100 ·
  14·28칸 특급 이상 행복 캡슐 한 번 + 행운별 100 (전설 천장에 센다). 28일 한 바퀴 = 티켓 30, 행운별 1440, 캡슐 2.
- 홈에 오면 '선물 달력' 창이 뜬다: 7칸 x 4줄, 받은 칸은 라벤더에 흰 ✓, 오늘 칸은 분홍 테두리로 숨 쉬듯 커졌다
  작아진다. 7·14·21·28칸은 상자(캡슐 칸은 분홍). 캡슐 칸은 '받기'가 뽑기 연출(1번)을 연다 -
  캡슐은 칸을 받는 순간 이미 들어와 있다(창을 그냥 닫아도 잃지 않는다).
- 처음 안내 중엔 창 없이 조용히 받는다. 옛 저장 선물 토스트가 뜨는 날은 그 뒤 3초에 연다. 그 사이 다른 창·싸움이
  떠 있으면 덮지 않고 토스트 한 줄로만 알린다.
- 오늘의 임무 창 맨 아래 '선물 달력 보기' - 받기 없이 보기만 (아래 줄은 다음 칸 선물).
- 옛 저장은 `daily_streak % 28` 칸에서 이어 간다. 저장 키 `cal_day`.

## 오늘의 도전 (매일 규칙을 비튼 판 하나)
- 열림: 처음 안내를 마치고(tut 99) 10판을 깬 뒤. 판은 `LaneData.daily_stage(cleared)` = 가장 앞에서 두 판 뒤(이미 깬 판).
- 규칙(`LaneData.DAILY_RULES`, 날 번호 % 5 - 이틀 연달아 같은 규칙은 없다). 모든 규칙에 벌레 체력 x0.9(`DAILY_BUG_HP`).
  바주카 잔치(충전 x2.5 · 웃음 x0.8) · 작은 군단(편성 앞 5칸) · 느긋한 웃음(웃음 x0.6 · 친구 값 x0.7) ·
  벽 없이(벽 역할 빼기) · 희귀까지만(특급·전설 빼기). 거르고 남는 게 없으면 꼬마 쿼카 하나.
- `LaneBattle.start(n, seed, mods)` 가 편성을 거르고(`LaneData.filter_lineup`) 수입·충전·값·벌레 체력에 곱한다.
- 보상(`LaneState.on_daily_win`): 하루 한 번 - 행복 조각 = 다시 깬 보상 x3(보물 보너스 반영) · 행운별 30.
  그 판 꽃 세 송이 조건까지 다 하면 티켓 1. 두 번째부터는 보상 없이 '다시 ▶'로 연습만.
  깬 판·꽃·응원(fails)은 건드리지 않는다 - 규칙이 다른 판이니까. 오늘의 임무(add_tally)에는 센다.
- 화면: 지도 탭 맨 위 카드(우두머리 얼굴 · 규칙 · 보상 · 도전 단추), 아직 안 했으면 지도 탭에 분홍 점.
  판 시작 배너 '오늘의 도전' + 규칙 안내, 위 판 이름 자리에 '도전: 규칙 이름'. 결과 창은 꽃 줄 대신 보상 줄, '다시 ▶'는 같은 규칙.
- 저장 키 `dch_day` (마지막으로 이긴 날). 균형: `SIM_DAILY=1 SIM_LOAD=<1장 끝 저장>` 으로 규칙별 씨앗 셋.
  1장 끝(10-8 판, 자동 봇)에서 느긋한 웃음만 33% 라 그 규칙의 벌레 체력을 0.8 로 낮췄다(→ 89%).
  나머지 넷은 100% (벽 없이는 남은 성 25~31% 로 아슬아슬). 손으로 하면 웃음이 모자란 규칙이 더 어렵다.

## 계속하게 만드는 고리 - 손맛 · 꽃 · 임무 · 달력 · 도전 (기획 2026-11)

> 사용자 요구: "이용자들이 계속 우리 게임을 멈추지 않고 할 수 있는 요소가 필요해. 나중에는 자동사냥 없앨 거야.
> 속도도 1배속이랑 3배속만 놔둘 거야."
> 원칙: **손으로 한 플레이에 보상한다** (자동이 사라져도 재미가 남게). 벌·시간 압박 없음. 놓쳐도 잃지 않는다.
> 날짜는 폰 날짜(`LaneGame._local_now() / 86400`, 로컬 자정 - 선물 달력과 같다).

위 다섯 절(판 기록 + 손맛 보너스 ~ 오늘의 도전)이 이 기획을 나눠 넣은 것이다. 여기는 전체 그림과 숫자만 모은다.

### 고리 지도
| 주기 | 무엇 | 손맛과의 관계 |
|---|---|---|
| 판 안 (몇십 초) | **손맛 보너스** - 손으로 쏜 바주카 한 방에 5·8·12마리 이상이면 웃음 +100·200·350과 충전 25%, 떼 막기 웃음 +150 | 자동이 쏜 바주카, 자동을 켠 동안의 떼는 받지 않는다 |
| 판마다 / 장기 | **꽃 세 송이** - 이기기 · 성 60% · 손맛 과제. 200판 x 3 = 600송이, 구역 꽃다발 | 자동을 한 번이라도 켠 판은 셋째 꽃을 쉰다 |
| 매일 | **오늘의 임무** 3개(쉬움·보통·손맛), **선물 달력** 28칸, **오늘의 도전** 판 하나 | 임무는 판 기록을 읽어 자동 소환·자동 바주카를 안 센다. 도전은 규칙을 비틀어 늘 쓰던 순서가 안 통하게 한다 |
| 매주 | **이번 주 도장판** 7칸 (임무 셋을 다 받으면 하루 도장 하나) | 도장 재료가 임무다 |

### 들어간 순서 (커밋)
0. **배속 1·3배** (`9d30296`) - `LaneData.SPEEDS = [1.0, 3.0]`. 단추는 '1배 ▶' ↔ '3배 ▶▶'. 옛 저장의 10배(speed_lv 2)는
   from_dict 의 clamp 로 3배로 읽힌다(테스트 있음).
1. **판 기록 + 손맛 보너스** (`9a6fa84`) - `LaneBattle.tally`(summons·kinds·shots·best_hit·multi5·kills·boss_cannon·holds·
   min_hp·cap_t·auto_used). `summon(id, manual := true)`·`fire_cannon(manual := true)`, `_auto_play` 는 false 로 부른다.
   `MULTI_HIT = [[12,350],[8,200],[5,100]]`, `MULTI_REFUND = 0.25`, `WAVE_HOLD = 150`, `WAVE_HOLD_AT = 0.5`.
   떼 판정은 떼가 다 나오고 다 쓰러졌을 때만 한다(벌레가 0.35초 간격으로 줄지어 나오기 때문).
2. **꽃 세 송이 + 구역 꽃다발** (`50933b0`) - `LaneState.flowers`(판 → 비트 1·2·4), `judge_flowers`.
   손맛 과제는 보통 판 n%3 (바주카 한 방에 3~6마리 / 웃음 꽉 찬 채 10초 이하 / 떼 한 번 막기), 우두머리 판은 바주카로 마무리.
   새 꽃 2·3마다 행운별 2(1장)·3(2장). 구역 꽃 20이면 행운별 20, 30이면 티켓 1. 옛 저장은 깬 판에 꽃 1만.
3. **오늘의 임무 + 이번 주 도장판** (`ab21284`) - `MISSIONS` 11개에서 씨앗 `today * 7919` 로 3개. 행운별 10·15·20,
   하루 한 번 공짜로 바꾸기. 셋 다 받으면 도장 1(하루 하나). 주 번호 `(today + 3) / 7` (월요일 0시).
   3칸 티켓 1 · 5칸 티켓 1 + 50별 · 7칸 특급 이상 캡슐. 처음 안내를 마치고 3판을 깬 뒤 열린다.
4. **선물 달력** (`617ddff`) - 옛 매일 선물의 연속 초기화를 없앴다. `cal_day` 1~28 은 받은 날 수만큼 나아간다.
   보통 날 티켓 1 + 30별, 7·21칸 티켓 3 + 100별, 14·28칸 특급 이상 캡슐 + 100별. 옛 저장은 `daily_streak % 28`.
5. **오늘의 도전** (`db2422c`) - cleared ≥ 10. 판은 `clampi(cleared - 2, 1, cleared)`, 규칙 다섯을 day%5 로 돌린다.
   벌레 체력 x0.9 (느긋한 웃음만 x0.8 - 시뮬 승률 33%여서). 하루 첫 승리에 행운별 30 + 행복 조각(다시 깬 값 x3),
   꽃 셋 조건까지 되면 티켓 1. cleared·꽃·응원은 건드리지 않는다.

### 경제 점검 (행운별 기준, 티켓 1 = 100별)
- 원래: 첫 클리어 행운별 합계 약 5850 (1장 1775 + 2장 4075).
- 임무: 하루 45별, 주 315별 + 도장판(티켓 2 + 50별 + 특급 캡슐) = 주 약 665별어치 (뽑기 6번쯤).
- 꽃: 평생 1000별 + 꽃다발(구역 20 x (20별 + 티켓 1)) = 약 3400별어치를 몇 주에 걸쳐 받는다.
- 오늘의 도전: 하루 30별 + 행복 조각(다시 깬 값 x3). 판 한 번 반 정도라 행복 조각 인플레이션은 작다.
- 달력: 28일 한 바퀴 = 티켓 30 + 행운별 1440 + 특급 캡슐 2. 옛 매일 선물과 총량이 비슷하고,
  7일째 큰 상자 네 번 중 두 번(14·28칸)이 특급 캡슐로 바뀌었다.
- **영구 힘(공격·체력 %)을 주는 보상은 넣지 않았다.** 그래서 밸런스(SimLane)를 다시 맞출 필요가 없다 - 아래 확인.

실제 사람은 손맛 보너스(웃음 +100~350, 1~4초어치)를 받아 조금 더 쉽다.

### 자동 소환을 걷어 낼 때 (나중)
배속은 이미 1배·3배 두 단계다(위 0번). 자동 소환은 아직 남아 있다 - 사용자가 나중에 없앤다고 했다.
- `LaneState.auto_summon`, HUD `_auto_btn`, 처음 안내의 '자동 소환' 단계(`_tut_battle_guide` 5 → 6)를 걷어 낸다.
- `summon`/`fire_cannon` 의 `manual` 인자와 `tally.auto_used` 검사를 지운다. 꽃 과제 줄의 '자동으로 싸우면 셋째 꽃은 쉬어요',
  결과 창의 '(자동은 쉬어요)', 임무의 '자동을 켠 판은 안 센다' 갈래도 지운다.
- `_auto_play` 는 SimLane 봇 전용으로 옮긴다(시뮬은 계속 써야 한다). 손맛 보너스를 봇도 받게 할지 정하고 SimLane 을 다시 돌린다.
  봇이 보너스를 받게 하면 웃음이 늘어 1장이 짧아질 수 있다.
